# 六吉、六煞与副曜

正曜为主。辅曜、煞曜、杂曜只修饰正曜与宫位，不得脱离正曜单断。六吉坐命皆可主聪明，但聪明种类不同。

## 六吉

| 星 | 性质 | 喜 | 忌 / 限制 |
|---|---|---|---|
| 左辅 | 阳土。明助、仁、忠厚、脚踏实地、台前。有自力：先自助再得人助。平辈贵人，偏男 | 会紫微、天府最能发挥；会太阳、太阴、七杀、天梁、巨门、天相增领导与开创。喜辰戌丑未，丑宫最佳。喜入命、身、福德、事业、奴仆、迁移、财帛 | 不喜与天机同宫，易进退失据。与廉贞同宫效果一般。不宜夫妻宫，易再婚。命无正曜而辅弼独坐，或正曜组合不吉，可主苛刻、压榨亲友。与疾病星同宫主病痛反复，此时不作吉星 |
| 右弼 | 阴水。暗助、智、幕后、变通、创意。助力小于左辅，行事出人意料 | 与紫微、天府得令再得吉扶，大限好，仍可富贵。化科增智与桃花，主异路、走捷径，须有稳定结构（如紫微、天府同缠）才可长期发挥 | 不见君（紫微、天府）则化科吉性减弱。不适合与天机化忌同宫。化科仍宜以“隐”为主，过度彰显招非议。夫妻宫右弼，男命可主再娶；化科再带煞，权重偏向后任或偏房 |
| 文昌 | 正路功名、证书文凭、内才、持久。贵气较足 | 大利考试、升学后期（高中以后至研究生博士，作用压倒文曲）。入财帛提高求财档次，赚钱较不艰苦 | 力量取决于同宫正曜。性质端正而保守 |
| 文曲 | 口才、非正统文艺、外才、变通、前期发展快 | 学习能力强；化科只利学习，因同时文昌化忌，故不必然利考试 | 化忌则贵气下降，配煞可仅主普通技艺。女命天同坐命不宜见昌曲，意志不坚 |
| 天魁 | 阳火。明显贵人、男性长辈或远强于己的平辈；明显机遇。文状元象 | 阳年、日生人命宫见魁较吉。太岁当头坐再加魁钺，吉性增加。夹紫微天相比夹天机天梁更能用其贵气 | 贵气极依赖正曜；主星平庸则难用。现代考试分数封闭阅卷时，考学力弱于昌曲；面试、赏识、政策变动时强于昌曲。不适合低贱职业 |
| 天钺 | 阴火。暗助、女性长辈或不知名的助力；侧面机遇。武状元象 | 阴年、夜生人命宫见钺较吉。余同魁 | 同魁。魁钺管大事不管小事 |

通例：

- 辅弼聪明主察人、处事；昌曲聪明主读书学问。辅弼有福气色彩，昌曲劳心。
- 辅弼助力来自众人、单力不大；魁钺助力来自少数人、单力大。
- 左辅可主贵、右弼可主富；昌主正路、曲主异路才艺；魁钺皆带财气但不是财星。辅弼入财帛，钱财来源连续，但辅弼本身不是钱。
- 失忠厚仁义（看同宫正曜与福德）则辅弼同照也不主助力大。
- 左辅化科增仁义、带薄桃花；右弼化科增智、桃花更重。现代物欲下左辅化科效果弱于古。

## 天马

与禄存或化禄同宫、对宫成禄马交驰，主奔走生财。宜命、财帛、田宅、迁移。田宅见之可在外置产。天马落空亡则减等。天梁落陷再加天马为梁马飘荡，主离祖。天巫见天马又得禄权科，为天巫赶马，从政可迁、从商有新机。

## 六煞

| 星 | 本质 | 可吉之时 | 主凶之时 |
|---|---|---|---|
| 擎羊 | 阳金。禄前一位。明抢、先发争端、小人 | 入庙（辰戌丑未）且煞少、吉星拱凑可主威权。午宫落陷与贪狼化禄、天同化禄同宫可作变景，不以凶论。七杀未宫不惧同宫，增威但主孤、宜防手术。武职、军警、司法面对争端可当工具星。甲庚年生人擎羊在卯酉杀气最重，但与紫微、天府同宫则减轻 | 命身疾厄见羊再加火铃空劫杀破天刑化忌，主伤残。夫妻无制主争吵；子女主冲突；父母主不睦、易破相。天机、廉贞同宫伤害大；天府同宫伤害小。流年疾厄天机擎羊加煞忌，防肢节伤。紫微午宫不喜羊陀。贪狼亥子不宜羊陀（泛水桃花） |
| 陀罗 | 阴金。禄后一位。暗缠、后发、妒忌隐患 | 入庙见吉可享受富贵。陀罗铃星同宫主磨炼后有成，宜男命，三方不宜再加煞忌 | 多数时候以凶论。与羊同理加重则孤克、伤身、六亲缘薄 |
| 火星 | 环境突变、明显创伤、来快去快。属“难趋避” | 贪狼同宫再见禄存或化禄成天火贪／铃贪，商人喜变化。庙旺火铃可增七杀气魄 | 火铃夹命为败局，运差又被煞忌引动可大起大落。分坐命宫父母宫多见父母离异或与父母缘薄。仅一颗在父母宫亦主少离父母 |
| 铃星 | 暗变、持久焦灼、来得慢 | 同火星，配贪狼可突发 | 同火星。爆发力弱于火、持久强于火 |
| 地空 | 从空而来从空而去；平白得、平白失。精神性重 | 逢吉则吉。舵手（正曜组合）强则浪里行舟可过 | 入财帛或与财星搭配则财气大损。命身财官迁见空劫又遇煞忌多，行运不利可重大破败 |
| 地劫 | 偏门、冷门、拉偏；明面劫夺 | 现代偏门技艺、新兴职业可见发达。不如地空那样明显改写他星性质 | 古法极忌。入财则来路特殊兼损耗 |

通则：吉可为凶、凶可为吉，看组合。羊陀对武职未必是祸。空劫严格说不是绝对煞，但入财必损。

## 杂曜（有明确断法者）

| 星 | 判定 |
|---|---|
| 天官 | 与紫微、天府、武曲化权同宫守命，不逢煞又得吉拱，主掌权得位。与巨门、昌曲、化科同宫主口才 |
| 天福 | 最宜福德，主享受；入命增福也增懒。与七杀同宫降低杀气、改善家庭。家庭仍须看田宅 |
| 天才 | 喜天机、天梁、天府、天相、魁钺、昌曲同宫。入福德、官禄而组合优亦主智。紫微同宫加成有限，除非紫微化科或午宫入庙；否则增智也增劳心 |
| 天寿 | 紫微更喜同宫，增寿与谋划。天梁、天府、贪狼同宫可长寿 |
| 红鸾 | 正桃花偏爱情婚姻；亦可主祥瑞。与禄存、化禄、武曲在财帛同宫主喜庆之财。坐命增相貌气质。不宜再叠廉贞贪狼天姚沐浴咸池，桃花过多主欲强、多次婚姻。不宜空劫。紫微不宜同缠（分心事业）。父母、夫妻不宜见，主第三者或多次婚姻 |
| 天喜 | 喜庆、添丁象强于桃花。已婚者流年命宫见天喜，家中添丁较常见。余同红鸾之宜忌 |
| 三台八座 | 载具、抬举、地位。喜入命、会日月紫府天相。喜辰戌丑未。会天机增奔波。会天马提层次，天马不宜空亡。与煞忌重则交通事故。流年会昌曲又有科星，可取考驾照 |
| 龙池凤阁 | 才艺、高洁。龙池偏实用，凤阁偏艺术。命身福德见之主骄傲不随俗；再会紫微天梁太阳华盖天巫更显。与煞忌同宫则贵气可略。入命宜天机；入田宅主宅美观 |
| 天刑 | 刑法、惩戒、锐器。与贪狼同宫可制桃花为吉。六亲宫见之主不睦。日月同宫多少刑父母。从事军警城管制者，三方见天刑危害有限 |
| 天姚 | 偏桃花，吸引力强。遇煞忌或咸池沐浴廉贞贪狼紫微天梁天同太阴，主风流。不宜魁钺辅弼（桃花增而助力降）。红鸾天姚同宫以天姚为主。女命不宜太阳天姚，男命不宜太阴天姚 |
| 恩光天贵 | 须见吉化才显。会煞则不主恩泽与贵。喜紫府天相辅弼魁钺 |
| 台辅封诰 | 须配吉星。台辅增权、封诰增口碑。台辅喜左辅，封诰喜右弼。助力圈子较固定，持久强于辅弼 |
| 天哭天虚 | 见吉不凶：天哭可主因声而名，天虚主虚荣。见煞：天哭主悲事，天虚入命身疾厄主体弱。天虚与禄或化禄同宫增消耗，但弱于空劫。鼠马年生人二星同宫，力增 |
| 蜚蠊破碎 | 蜚蠊主诽谤；遇巨门化忌最不利。破碎主分离；遇武曲化忌、羊、火须防意外。见吉可略 |
| 孤辰寡宿 | 男命不宜孤辰坐命，女命不宜寡宿坐命。拱冲命身则六亲缘浅。配吉则孤高自立；配重煞只主怪僻。孤太重须看福德能否自娱 |
| 天月 | 疾病星。不宜命身疾厄及与煞同宫。与禄或化禄同宫可因医、药得财。吉多则只主小拖延 |
| 天巫 | 传承、遗产。最宜田宅。见煞忌则继承减。疾厄见煞忌主遗传倾向。天巫赶马见上 |
| 解神 | 解散煞力，命宫可逢凶化吉。不宜六亲宫；夫妻再加煞忌主离别 |
| 阴煞 | 小力凶星，须配其余煞忌才显。可主小人、莫名之事。疾厄与天月同宫主查不出的病象。庙旺太阳最不畏 |

长生十二神、将前十二神等神煞不计入填宫正曜，不改变“无正曜”判定。

## 使用限制

- 杂曜等级划分（甲乙丙丁戊）本体系不用：实际论命时小星可压过大星。
- 身体、伤残、手术、遗传病只作术数取象，不作为医疗事实。
- 未在上表列出的杂曜，有则记象，无确定规则则不扩写吉凶。
