# 专题断法参考：财运 · 学历 · 生育子息 · 姓名取用

## 看财运

**宫位分工**
- 财帛宫（主看）：进财是否顺畅、流动资产多少、有无破财与周转不灵。
- 命宫（主看）：格局层次与承载财富的根基，回答"此人能否担得起财"。
- 田宅宫（主看）：固定资产、名下产业、能否积蓄留存。
- 身宫（参看）：后天着力处与守成能力。
- 事业宫（参看）：财从何处来、财源是否稳定。
- 福德宫（参看）：享用与耗用倾向，以及是否有意外之财的心态基础。
- 迁移宫（参看）：外出际遇与机会多寡。
- 父母宫（参看）：可承接的外部资源与荫庇。
- 大限、流年（动态）：先天缺陷能否被补足，先天好格会否被破坏。

**判断步骤**
1. 先定格局大小：命宫正曜是否庙旺，三方四正有无吉星吉化朝拱。此处的吉星包含左辅、右弼、文昌、文曲、天魁、天钺、禄存，也包含性质偏吉的正曜（如入庙的紫微、天府、太阳、廉贞、武曲、天梁）；正曜不入庙则吉性减弱。
2. 看命宫、身宫定根基：命身俱佳者遇困能解，命身不佳者纵得一时之财亦难留。
3. 看财帛宫本宫：先认同宫正曜，再论禄存、化禄、天马与煞忌，不可脱离正曜单断辅煞。
4. 看田宅宫定积蓄与库存能力，再补看事业宫、福德宫、迁移宫，确认财源与耗用结构。
5. 找病点：若他宫皆佳而某一宫（常见为财帛宫）煞忌交侵，即以该宫为病点，整体层次被其拖累。
6. 排大限走势：病点被补则财运转好，好格被破则由盛转衰；先天格局大者，遇好限可有大幅跃升。
7. 结论用相对层级表述（如温饱、小康、富裕、大富），不给具体数额。

**关键星曜与四化**
- 财帛宫喜武曲、天府、太阴等财星坐守，纵见煞星一般亦可达小康层级。
- 财帛宫见武曲化禄、太阴化禄，金钱流动顺畅，少见周转困难；若既有化禄，三方四正又会禄存、天马、文昌、文曲、左辅、右弼、天魁、天钺，则财气大增，从事何业皆能得利。
- 太阴在财帛宫以庙旺为吉，落陷则财气减等；无化禄而与天同化禄同宫，财气亦旺；与天机化禄同宫则财气一般、破耗较多；三方四正借会巨门化禄亦利财。
- 天府在财帛宫喜见左辅、右弼，增强赚钱能力；得禄存同宫主善理财；见地空、地劫同宫则财气减等。
- 地空、地劫在财帛宫主赚钱不易、易破财、资金流动不畅，不等同于"赚不到钱"。与武曲、破军、太阳、天机同宫属较差结构，纵三方四正佳，多止于小康而难大富；与廉贞、贪狼、七杀同宫影响较轻；与化禄同宫主财来财去、难以积蓄；与禄存同宫则财气大降且失去稳定性，有钱即散、聚财极难。
- 武曲在财帛宫构成铃昌陀武者财气减等，有破败危险；若同时武曲化忌，属破大财的结构。
- 擎羊、陀罗及其余煞星、化忌引动官非纠纷，可致破财至贫。
- 禄马交驰、禄马配印出现在财帛宫、福德宫、命宫、迁移宫，并得其余吉星吉化拱凑者，发家致富的可能性高。

**成立条件（判富）**
1. 格局宏大者。
2. 格局一般但命宫、财帛宫、田宅宫俱佳者。
3. 格局一般但连续数个大限走吉者。
4. 禄存、化禄落于命宫、身宫、财帛宫、田宅宫、事业宫、迁移宫，又有其余吉星吉化拱凑者。
5. 事业宫、命宫、迁移宫俱佳，仅财帛宫为病点，而该病点在某限被补足者。

**成立条件（判贫）**
1. 格局卑弱，三方四正煞忌交冲而无吉星解救，大限又走衰；命、身、限三者俱衰者层级最低。
2. 格局卑弱且命宫、田宅宫、财帛宫俱差。
3. 原盘格局尚可，但行至破大财之限（如铃昌陀武叠武曲化忌），家业散失。
4. 格局不错但因官司纠纷破财，多见擎羊、陀罗及其余煞忌引动。

**不成立条件**
- 不可单凭财帛宫见地空、地劫断定贫穷：该组合由固定的出生月、时决定，适用面过广，无区分度。
- 不可单凭财帛宫有禄存、化禄、天马即断财运好，亦不可因其缺席即断财运差。
- 不可把"赚钱不易"改述为"赚不到钱"。
- 财帛宫破而其余宫位佳者，不得直接判贫，须先判为病点再看限运。
- 从事收入间歇性强的行业或以技术求财者，空劫、禄存受冲的负面判定应予弱化。

**判断边界**
- 盘上可看：财运相对层级、进财顺畅度、聚散倾向、破财与官非风险、财运好转或退步的时段。
- 盘上看不了：具体金额、资产数值、行业收入水平、单笔交易成败。

## 看学历

**宫位分工**
- 命宫（主看）：格局大小，决定学历的基本上限。
- 父母宫（主看）：父母与师长的栽培力度，以及处事是否有头脑。
- 事业宫（参看）：学业与考试的直接对应宫位。
- 夫妻宫（参看）：与事业宫相对，其文昌、文曲可照入事业宫而利考学。
- 身宫、福德宫（参看）：后天着力与用功持续性。
- 田宅宫、财帛宫（参看）：就学的家境与物质条件。
- 第二大限、第三大限（动态）：前者对应基础教育至升学阶段，后者对应继续深造阶段；水二局、木三局起运早，进入第三大限亦早，是否读研读博多在此限见。

**判断步骤**
1. 定格局大小，格局大者学历一般高于格局小者。
2. 看父母宫吉煞：吉星多者智慧与管教条件俱佳；一至两颗煞星不碍，三颗以上则以破论。
3. 看文昌星状态：文昌司掌证书、文凭，为考学的核心标志星；同时查命宫、身宫、事业宫是否见文昌化忌。
4. 排第二大限，看是否见阳梁昌禄、日月昌曲、文昌化科及吉扶。
5. 排第三大限，判断深造层级。
6. 参考田宅宫、财帛宫是否构成就学的物质障碍。
7. 结论以学历层级区间表述，允许相邻一档误差。

**关键星曜与四化**
- 阳梁昌禄、府相朝垣、科禄巡逢、月朗天门、辅拱文昌等大格局，多见高学历。
- 文昌为文凭之星；文昌化科、文曲化科主考试顺遂；文昌化忌落命宫、身宫、事业宫主考学不顺。
- 阳梁昌禄、日月昌曲会入第二或第三大限三方四正，主该限学业有成。
- 夫妻宫见文昌、文曲，照入事业宫，利于读书考试。
- 父母宫吉星提升的是通达处事之能，与狭义的智商不是同一概念：智商高而处事一根筋者，多见父母宫有问题。

**不成立条件**
- 不可把大格局一律等同于高学历：偏重财利的格局（如火贪格）格局虽大，学历反可能不如未成格者。
- 见文昌化忌不得径断学历低，若同时见文曲化科等吉星，仍可能有高学历，须合参整盘与限运。
- 先天格局佳、第二大限佳、文昌状态佳，但父母宫、田宅宫、财帛宫俱差者，可因家境中断学业，不得只凭前三项定论。
- 是否继续深造属个人选择，盘上不能锁定。

**判断边界**
- 盘上可看：学历的大致层级、求学过程是否顺利、哪一限出成绩、是否有中断风险。
- 盘上看不了：具体院校、专业、分数、考区竞争强度与教育资源差异，这些属盘外因素，须结合实际情况修正结论。

## 看生育与子息取象

本节规则仅为术数体系内的取象推演，不构成医学结论，不得用于任何选择性决定；输出时须同时给出不确定性，不作确定性断言。

**宫位分工**
- 子女宫（主看）：子息有无、多寡、先后、性别倾向。
- 田宅宫（主看，子女宫对宫）：居家环境是否安宁，影响受孕与子女运势，兼看家宅兴旺与后代。
- 命宫（参看）：整体格局层次，女命尤重。
- 大限子女宫、流年子女宫（动态）：定应期与当胎取象。
- 配偶命盘的子女宫（参看）：双方合参结论更稳。
- 胎次对应：第一胎看子女宫，第二胎看财帛宫，第三胎看疾厄宫，依次顺推。

**判断步骤**
1. 先定本人命盘格局，女命格局越好、子女宫越好，得子的倾向越强。
2. 看本命子女宫吉煞：吉星吉化多者偏男；桃花星（如天喜、天姚）多者偏先得女，且女多子少。
3. 遇子女宫为七杀、破军、贪狼：命格一般或卑弱者偏女，命格佳者可得男，不得单据此宫定论。
4. 看大限子女宫，确定该十年的子息倾向。
5. 看流年子女宫：桃花多者偏女，吉星吉化多者偏男；流年子女宫与本命子女宫重叠之年为应期之一。
6. 与配偶命盘的子女宫合参。
7. 校正：曾有堕胎、流产者，子女数目与先后次序会偏移，须先问明再断。

**关键星曜与四化**
- 吉星吉化聚于子女宫主子息顺遂、偏得男，判断时不按左辅右弼、文昌文曲的阴阳属性分男女。
- 桃花星聚于子女宫主偏得女、且先得女。
- 擎羊、破军、七杀、天刑、火星、铃星等煞星聚于子女宫，主得子困难、生育有阻碍，宜迟不宜早。
- 子女宫极坏者兼主婚姻不稳、迟婚或婚姻受阻。
- 田宅宫破败（居处嘈杂、逼仄、不通畅）不利子女运势。

**不成立条件**
- 不可仅凭辅佐单曜的阴阳属性（以文昌、左辅、天魁主男，文曲、右弼、天钺主女）定性别，此法不稳。
- 不可仅凭子女宫见七杀、破军、贪狼断定生女，同一子女宫结构在男命与女命上结果常相反，须整盘合参。
- 未取得生育年份与大限信息时，不得断头胎性别。
- 不得对未确认怀孕的情形作性别取象。

**判断边界**
- 盘上可看：子息多寡的倾向、生育难易、先后次序倾向、适合生育的时段（流年子女宫吉星吉化拱凑之年为宜）。
- 盘上看不了：确定的胎儿性别、胎数、健康状况与医学指标；此类判断必然存在误差，结论只作倾向陈述。

## 姓名取用

**与命盘的关系**
- 姓名作用于第一印象与人际交往层面，用以强化命盘的优势或弥补命盘的劣势，不改变命盘格局本身。
- 主看命宫（正曜性质、庙旺利陷、煞忌情况）定喜忌；参看格局大小判断宜强宜柔；参看桃花状况决定用字的刚柔取向。

**核心规则：含义、发音、避讳**
1. 含义：取象义积极、阳光、吉祥者，避免引人联想到悲观、低落、粗鄙的字。
2. 发音：不宜拗口；须排查谐音可能引申出的不良含义。
3. 避讳：不宜与同时代高知名度公众人物同名同姓，以免混淆；太阳坐命者不宜取与父辈姓名相同或偏旁相近的字。

**判断步骤**
1. 定命宫正曜、庙旺利陷与煞忌，判格局大小。
2. 定喜忌：性质与本人相符者为喜，相悖者为忌；过旺者宜收敛，不足者宜激发，已见煞忌而偏刚者不可再刚。
3. 按喜忌选定字的象义取向。
4. 校发音与谐音，再校避讳。

**按命宫正曜的用字取向（举例限男命，须依具体命盘调整）**
- 紫微坐命且格局大：宜强势、富领导意象之字。
- 天机坐命且格局大：宜在彰显才智之外兼取扎根意象，可用土字旁。
- 太阳坐命且格局大：先辨光芒是否发散太过，过者宜取带收藏、储存意象之字。
- 武曲坐命且格局大：宜取威势、开拓、进取意象之字，金字旁一般可用。
- 天同坐命：缺激发之力者取带震动、锐利意象之字；已有激发之力者取守成、恒常意象之字。
- 廉贞坐命且格局大：宜取通达、顺畅意象之字；此星多为双星结构，须参同宫正曜而定。
- 天马坐命并构成禄马交驰者：可用走之底之字。
- 桃花过旺而欲减少感情干扰者，女命可用刚性用字；命局孤寡、缺桃花而有婚配意愿者宜用柔性用字（如三点水）；若本人无婚配意愿，则不受此限。
- 武曲、七杀在卯坐命又见擎羊、陀罗、地空、地劫、火星、铃星者，无论男女皆不宜刚硬用字，过刚易折，宜取温和意象之字。

**不成立条件**
- 不以笔画分格的数理法或单纯五行补足法作为主要依据；象义为先，数理为次，象义差者，数理再吉、五行补得再妙亦不取。
- 不得由姓名反推命盘结构，亦不得以改名替代限运判断。
- 上述用字取向为示例，不可脱离具体命盘套用。

**判断边界**
- 可判定：姓名与命盘喜忌是否相符、用字宜刚宜柔、是否犯发音与避讳之忌。
- 不可判定：改名后的具体成效幅度、时间点，以及姓名对寿元、财数等的量化影响。
