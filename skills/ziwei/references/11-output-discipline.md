# 输出设计与质量检查

目标是让用户一眼看懂“盘是什么、结论是什么、为什么、何时需要验证”，而不是让每次回答长得一样。

## 共同写法

1. **盘面事实和术数判断分开。** “真太阳时 18:20、命宫巳、天相得地”是盘面；“更适合在明确制度中发挥协调能力”是解释。
2. **结论紧跟依据。** 每个重要判断后立即说明相关宫位、正曜、四化或限运，不在末尾堆一大串星名。
3. **写现实表现。** 少用“中层、贵格、吉凶参半”，改写为能否独立主导、适合何种组织方式、收入来自稳定积累还是变化流动、关系冲突来自哪里。
4. **保留条件。** 使用“结构更支持、在……条件下更明显、若……则减弱”，不把术数解释冒充已发生事实。
5. **控制术语。** 格局名可以保留，但第一次出现要用一句白话说明它在这张盘中实际代表什么。

## 盘面摘要

只写用户能核对、且会影响断盘的三至五行：

```text
男命｜公历 1993-02-05 18:26（山东威海）
真太阳时 18:20，酉时；校正前后未跨时辰
四柱：癸酉 甲寅 丁巳 己酉
命宫巳：天相得地；身宫落迁移亥；土五局
生年四化：……
```

地点须使用工具实际解析结果。若临界、跨时辰或时间不精确，把警示放在摘要中，不埋在末尾。四柱用于核年干与时辰，不另起八字分析。

## 只排盘或核盘

建议顺序：

- 输入时间、解析地点、真太阳时与校正量；
- 四柱、命宫、身宫、五行局、生年四化；
- 命财官迁的主星组合；
- 缺项、冲突或时辰边界。

用户没让解读时，到此停止。

## 原局概览

“算一下／看看这个”默认使用，不把答案缩成一个财富或身份等级。

1. **总纲：** 二至四句说清主要驱动力、最能发挥的环境和核心代价。
2. **做事方式：** 命身、福德如何组合；给优势与容易失衡处。
3. **事业与财帛：** 分别说明事业组织方式、进财方式、守财条件，不把“能赚钱”等同于“能积累”。
4. **关系与家庭：** 只谈互动模式、助力与冲突条件；不凭盘确认出轨、离婚或对方品行。
5. **关键条件：** 写一个最能使整盘向上或向下兑现的现实条件。

除非用户问“现在、今年、未来几年”，原局概览不强制附当前与下一大限。

## 专题分析

建议顺序：

- **结论：** 先回答所问，避免“有好有坏”。
- **依据：** 二至四条，每条都是完整组合链，而不是单星释义。
- **现实分叉：** 写清在什么工作方式、关系模式或资源条件下分别如何表现。
- **建议：** 只有用户问建议，或盘中条件能对应当事人可控动作时再给。

专题之外的宫位只有在会改变结论时才出现。

## 限运与应期

建议顺序：

- **原局底色：** 这件事本来有没有条件。
- **当前大限：** 大限命宫叠原局哪一宫，十年主题如何改变原局。
- **目标流年：** 哪个组合被再次触发，是机会、压力、决定还是收尾。
- **窗口：** 只有大限、流年同题后才缩到月份；只有用户确需且数据齐全时才到日时。
- **可验证信号：** 给现实中可观察的先行变化，帮助用户判断象是否正在兑现。

不能把单一流曜写成“某日必发生某事”，也不能把当前日期自动塞进纯原局问题。

## 规则解释

按“定义 → 成立条件 → 加强／破坏条件 → 例外 → 常见误判”回答。不同流派口径有冲突时分栏说明，不暗中拼成新规则。

## 不合格表达

| 不合格 | 改写方向 |
|---|---|
| “总体中层，有机会也有压力” | 说明机会从哪一宫哪组星来，压力会具体损害稳定性、掌控权还是留财 |
| “贪狼化忌，所以感情不好” | 先看贪狼所在宫、庙旺、同宫与三方，再说明化忌改变的是欲望、关系投入或满足感 |
| “官禄空宫，所以没事业” | 借对宫正曜，合看本宫辅煞及命财迁 |
| “今年流年很好” | 说明原局哪条主链被大限与流年共同补强，以及现实中会先出现什么信号 |
| “女命某星必克夫” | 改为现代可理解的互动模式，并明确需要哪些组合才成立 |

## 最终自检

- 用户的问题是否在前四分之一篇幅内得到直接回答？
- 盘面摘要是否准确且没有混入吉凶形容词？
- 每个主判断是否至少有两个层面的盘面依据？
- 是否出现可套任何人的空话、重复结论或无关宫位清单？
- 是否把“可能的象”写成了疾病、犯罪、出轨、死亡、胎儿性别或交易结果的事实？
- 时间判断的精度是否超过出生时间与运限数据的精度？
- 若存在时辰、地点或流派不确定性，是否说明它会改变哪部分结论？
