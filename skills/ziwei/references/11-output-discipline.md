# 输出收束与边界

## 结论漏斗

完整查盘用于保证不漏反证，不等于把十二宫全部写给用户。落笔前先完成四项收束：

1. 明确用户问哪一个结果及期限。
2. 判定命盘最多支持到哪个事件阶段。
3. 选出一条足以回答所问的主链。
4. 找出会推翻或限制主判断的最强反证。

默认输出顺序：

- **盘头：** 先给核对用的一行结构，再写判断。必备：性别、公历、真太阳时与时辰（写明单盘或并盘）、四柱年月日时、命宫地支与正曜（庙旺、本宫四化）、身宫落宫、五行局、命主身主、生年四化四字。四柱抄排盘顶层 `四柱` 的年柱、月柱、日柱、时柱；时柱必须与 `derived.chinese_hour` 一致。盘头不是断语，不加吉凶形容词。
- **判断：** 一至三句给出一个主判断，说明当前层次、能走到哪一步。不要先罗列十二宫，也不用“有好有坏、存在机会、可能反复”代替结论。
- **主因：** 只展开最能决定结果的组合链，通常二至四个节点：主宫正曜、同宫或三方关键星、四化、限运冲起。第二条链只有在它能改变层次、成败或时间时才写。命宫三方四正 = 命宫、财帛宫、官禄宫、迁移宫；用三合组（寅午戌、亥卯未、申子辰、巳酉丑）加对宫核对，禁止把辰戌丑未四墓当成命三方。
- **过程与应期：** 最多三个有区别的窗口，分别标明对应大限、流年或更宽区间，以及对应的是消息、推进、确定还是完成。问原局格局时写当前大限与下一限即可。没有三层四化与宫位重叠支持时，不落到具体日。
- **限制：** 只保留一个最关键的未决条件或相反信号，并说明它会把结论改到哪一步。
- **可做之事：** 用户问建议，或现实动作对应盘中明确病点时再给。建议须是当事人自己能做的事；不越权代做媒、代做投资、代做医疗决定。

盘头示例（原局）：

```
男命 · 1953-06-15 · 真太阳时 03:15 · 寅时（昼生，单盘）
四柱：癸巳 戊午 丁酉 壬寅
命宫辰 贪狼庙化忌 · 身宫在官禄申 · 土五局 · 命主廉贞 身主天机
生年四化：破军禄、巨门权、太阴科、贪狼忌
```

禁止：

- 排盘已给出四柱，正文却只写“核盘已齐”或只报真太阳时。
- 用四柱另起八字、日主、十神、大运断法。
- 盘头之后再贴十二宫表或把每个宫位写一遍。
- 把 `ai_context` 里未核对的三方四正当成结论；须用命、财、官、迁四宫复核。

## 具体性

若删除星曜与宫位名称后，一句话仍可套用于大多数命盘，例如“过程有压力”“后面可能反复”“条件会有调整”，就删去或改写为具体宫位、星曜、层次和触发条件。结论不在多个段落换词重复。

候选含义通常只输出最贴题的一项；只有两项证据接近且会导致不同结论时，才增加一个备选，并写清哪条现实信息可以区分。

用户明确要求全盘、教学式或逐宫分析时可以展开，但仍先给盘头、主判断和主链。

## 层次用语

富贵、学历、事业用相对层级表述，如温饱／小康／富裕、普通／中层／高层，允许相邻一档误差。不输出具体金额、资产数值、院校名称、分数、职位级别或寿数。

宽题未锁定子目标时，只判断当前状态、下一阶段和一个决定条件，不自行并列婚姻、事业、财运、子女多条人生事件。

## 成立阶梯

| 所问 | 先锁定 | 不得直接跳到 |
|---|---|---|
| 事业 | 能做什么、是否稳定、权柄大小 | 具体职位、必升必败 |
| 财运 | 进财是否顺、能否留存、层级 | 金额、单笔交易、必富必贫 |
| 婚姻 | 助力、刑克、稳定性 | 出轨、离婚日期、对方外貌细节 |
| 学业 | 层次区间、是否中断 | 录取、名校、分数 |
| 限运 | 原局重点被补还是被破 | 某日发生某事 |

## 不可越权

解答命盘的工作是提供信息。对方是否采纳、如何改变，仍由对方自己决定。不得把命盘结论写成必须执行的人生规划，也不得在对方没有所问时主动给全盘命运鉴定。

## 不得确认的事实

星曜、神煞、身体部位和六亲象只属于术数取象：

- 不作为医疗诊断、器官病变、治疗效果、死亡或寿命断言。
- 不作为犯罪、出轨、性关系或他人隐私事实的确认。
- 不作为胎儿性别、胎数或生育医学指标的确认；子息规则只作倾向，且须同时给出不确定性。
- 不作为证券、房产或交易指令；财象不作到账保证。
- 不把“横发”“暴败”改写成已经发生或必然发生的事件。

缺字、排盘不全、杂曜落宫与规则冲突时，标为缺项或按规则重定其宫，不得靠想象补全。
