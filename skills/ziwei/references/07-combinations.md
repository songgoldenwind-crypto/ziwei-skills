# 基本组合、基本变化与格局判定

## 一、三种基本组合

断盘时三层组合必须同时成立，缺一层即为判定不完整。

### 1. 星曜 + 星曜

- 定义：若干星曜共坐一宫，称同宫（亦作同度、同缠），如紫微与天府同宫、廉贞与天相同宫、贪狼与禄存同宫、文昌与文曲同宫。
- 入手点：先确定同宫诸曜的性质叠加方向，再确定三方四正会照而来的星曜。
- 输出要求：必须给出合成后的性质，而不是分别罗列各星原义。

### 2. 星曜 + 宫位

- 定义：同一组星曜落入不同宫位，含义随之改变。同为紫微天府，落财帛宫与落疾厄宫的结论截然不同。
- 入手点一：按所落人事宫位的事类改写星曜结论。
- 入手点二：按所落地支宫位定庙旺利陷，并判断地支五行对星性的加强或压制。

### 3. 宫位 + 宫位

- 十二人事宫位排序固定、位置不固定；十二地支宫位（子丑寅卯辰巳午未申酉戌亥）位置固定。
- 每隔三宫的宫位互相强烈影响，构成三合宫；命宫、财帛宫、事业宫是最常用的三合宫。
- 除三合宫外，对宫、夹宫、暗合宫、太岁宫、身宫，以及大限流年宫位与原局宫位的重叠，都会改变宫位含义。

### 4. 单一维度判定的禁止条件

- 只用"某星入某宫"（即只用第二种组合）断盘，判定不完整，不得作为最终结论。
- 原因一：同一星曜在不同同宫组合下性质已被改写。
- 原因二：同一宫位被三合、对宫、夹宫及大限流年重叠持续修正。
- 处理方式：凡结论仅依据单一维度得出，须回到三层组合复核后方可输出。

## 二、四种基本变化

### 变化一：星曜同宫或会照的互相作用

- 判定方法：先列本宫同宫诸曜，再列三方四正会照诸曜，按第三节的相互作用原则合成性质。
- 此层变化可派生的组合数量极大，不存在穷举表；未覆盖的组合按原则推导。

### 变化二：星曜自身化禄权科忌

- 判定方法：取义为"某星朝该化的方向改变"。
- 化禄：朝温和、和善、有钱、赚钱、享受方向改变。
- 化权：朝积极、严肃、稳定、拼搏、掌权、控制欲方向改变。
- 化科：朝斯文、学识、传播、名气、考运方向改变。
- 化忌：朝不足或过度、不满意、不开心等负面方向改变。
- 化禄与化科的区分：化禄的斯文无架子，化科的斯文有架子；化科另主动求学、求博。

### 变化三：星曜自身无四化而在三方四正遇禄权科忌

- 判定方法：四化性质会传染给同宫星曜，也会传染给三方会照到的星曜；影响力度视组合而定，有时很大，有时可忽略。
- 受化禄影响者变柔和、沾财气。
- 受化权影响者变化较多：可能被激励、被控制、变稳定、变激烈，也可能受损。
- 受化科影响者变斯文、清高、有才华，也可能变柔弱、不切实际。
- 受化忌影响者多朝负面发展，转正面者少。
- 示例判定：太阳化忌再遇擎羊、天刑，则擎羊、天刑同样带上强烈不满意的性质，主惹是非、生冲突。

### 变化四：大限流年宫位移动导致星曜互涉与三层四化作用

- 判定方法：须同时处理前三种变化，并分别持有原局、大限、流年三个体系的宫位与四化。
- 再看三层四化对同一宫位的冲起情况，合成吉凶。
- 禁止省略原局层直接取流年层。

### 三吉化的判定约束

- 禄、权、科不等于必吉；三吉化既是助力也是压力，化权带来的压力最明显，身宫化权者压力大于常人。
- 逐项确认：该化落在哪颗星、该星在哪一宫、该星庙旺利陷状态如何、三方四正组合如何、该大限该宫出现此化是否合适。
- 示例判定：太阴在福德宫化权，三方四正无吉星，反会天机化忌及擎羊、陀罗、火星、铃星、地空、地劫，断为要求高而所得少、对现状严重不满。

### "化忌不忌"的成立条件

- 贪狼化忌、太阴在亥宫化忌、四墓宫化忌三类"不忌"说法均有条件，不可作无条件断言。
- 贪狼化忌在命宫，命宫无煞且有吉星、三方良好者，可按不忌论；在事业宫大致同理。
- 贪狼化忌在命宫与禄存同宫构成羊陀夹忌者，不作不忌论。
- 贪狼化忌落夫妻宫、子女宫者，男女命皆不作不忌论；加羊、陀、火、铃、空、劫同宫危害大。
- 贪狼化忌在夫妻宫即使无凶星，只要加红鸾、天喜、天姚，亦断为不吉。
- 太阴化忌在亥宫必得禄存、化禄会照，若坐命宫且三方四正较好，可按不忌论。
- 太阴化忌落夫妻宫、子女宫则不吉，再加地空、地劫同宫为大害。

## 三、星曜同宫会照的相互作用原则

1. 作用是双向的：甲星改变乙星的同时，乙星必改变甲星，两个方向都要给出结论。
2. 同性质相叠则该性质突出：太阳有贵气、天梁有贵气，太阳天梁同宫则贵气突出，坐命者易受人尊敬或自视甚高。
3. 性质突出不等于可发挥：有吉星吉化者凭实力或地位获得尊敬；全无吉星又见恶煞者社会地位多半不高，只余"自觉高贵"的心理状态。因此见太阳天梁不可直接断显贵。
4. 异性质相叠则相互削弱或改变：紫微主贵、火星不主贵（构成火贪格时例外），紫微火星同宫的净效果是火星降低紫微贵气，同时紫微被火星的浮躁与突发性质影响而转为暴躁。
5. 上条的宫位化用：紫微火星在夫妻宫且三方四正不见任何吉星吉化、又不构成火贪结构者，不断配偶社会地位高，而断配偶脾气急躁。
6. 不同正曜抗煞能力不同，配同一煞星后果不同：紫微自身有抗煞能力，紫微火星坐命虽亦坎坷不安稳，程度轻于巨门火星坐命；巨门抗煞力弱，与火星同宫即主际遇不佳甚至漂泊。
7. 抗煞对比只是本宫层面的理想化对比，不得据此定论；须加入三方四正与大限走势：紫微火星坐命而三方四正煞星众多、大限又差者，可比巨门火星坐命更坎坷。
8. 星曜、宫位、四化三者共同判定，不得抛开宫位单论星曜。

## 五、格局判定的限制

1. 成格与否只是第一层结论，仍须结合当事人的实际处境与男女命断法差异后再输出。
2. 男命、女命同盘不同断：七杀、破军坐命主一生有一段辛苦颠簸期，对男女命的吉凶权重不同，不得统一处理。
3. 成格不等于各方面俱佳：偏重发财的格局在学历、名位上可能反不如未成格的命盘。
4. 紫微斗数不存在百分百通用的公式，凡表中条件未齐者，只作倾向性描述，不作定论。
