# 大限、流年、流月、流日的推断规则

## 一、大限的划分与起限口径

- 命盘将一生分为十二个大限，每个大限十年，合计一百二十年。
- 划分依据：一是人类寿命上限；二是天干每十年重复一次，十年为一旬，代表时间的小轮回，六旬构成一个甲子的大轮回。
- 当代通行口径：以命宫起第一大限。成立条件是个人天赋能够自由发展的环境，即家庭对个人发展的压制较小。命宫代表与生俱来的天赋，幼年即可显现未来发展方向。
- 早期口径：以父母宫、兄弟宫起第一大限。成立条件是家长制环境，个人必须按家庭要求发展，天赋难以自由发挥。
- 早期口径的现代适用条件：出生地经济落后、家庭约束强，且父母宫、兄弟宫组合很差时，本人受家庭拖累、才华被埋没，此时仍按早期口径判定更贴合实际。
- 当代口径的适用条件：所在地区经济发达、培训与教育资源充足、家庭管教方式较宽松，命宫天赋容易被发掘与发挥。
- 判定方式：先核查出生地与家庭条件，再决定采用哪一口径起限；两种口径不得混用于同一盘。
- 第二大限（当代口径下）落父母宫或兄弟宫，对应青春期：此期得良师、良友、家庭和谐者发展顺利；家庭出现变故或交友不慎者朝坏的方向发展。
- 年龄段权重差异：幼年期对家庭负面事件的记忆与影响较浅；青春期已懂事，家庭分裂对学业与心态的破坏显著。

## 二、推断顺序

推断大限、流年必须按以下步骤执行，不得跳步。

1. 先排原局并读原局：定命宫、身宫，定十二宫星曜组合与庙旺利陷，定生年四化落点。
2. 找出原局重点：包括原局已成的格局或凶构、三方四正吉星与煞星的集中处、生年四化冲起的宫位。
3. 由原局重点推出应重点监测的限年方向。例：原局贪狼在子宫与擎羊同宫坐命，构成泛水桃花，主因色生灾，则应重点检查桃花较重的流年，以及夫妻宫出问题的流年；桃花越重的流年对此构越不利。
4. 再分析大限：看大限命宫所落原局宫位、大限宫位的星曜组合、大限四化的冲起情况。
5. 最后分析流年：看流年命宫星曜组合，并叠加原局、大限、流年三层四化。
6. 综合判断：某宫三方四正吉星汇聚，又被大限、流年吉化冲起者，一般主吉；某宫三方四正煞星较多，又被化忌冲起者，一般主凶险、灾厄、破财、疾病、官非。
7. 示例判定：流年命宫既有桃花星，又有擎羊、陀罗、地空、地劫、火星、铃星、化忌冲照，而原局本有泛水桃花者，该年很可能因桃花生灾。

不看原局直接看流年的做法，只能看准一部分，必然遗漏原局层面的重点，禁止采用。

## 三、原局格局与流年星曜的匹配

- 原则：原局所缺的性质，走到能够互补的星曜限年为佳。
- 天同主福气，是紫微、太阳、天梁三曜所缺乏的特质；紫微坐命、太阳坐命、天梁坐命者行天同限年可起互补作用。
- 天同的限年对天府坐命、天相坐命者一般也属有利，但具体改变须综合原局、大限、流年三者共同判定。
- 原局紫微破军在丑宫、未宫坐命，又见吉星吉化、格局较大者，一般喜行太阴的大限流年：太阴为财星，主实际利益，且此时太阴必与太阳相对，主财富增加并伴随地位与知名度提升。
- 同一紫微破军坐命者行太阳的流年，好处不同：多主名气提升，实际利益较少而支出较大。
- 紫微在午宫坐命、太阳天梁在卯宫坐命者，一般喜行天同巨门的流年；巨门主艰苦、天同主享福，合为先苦后甜，多为开运之年。
- 上条延伸：若流年命宫为空宫而借迁移宫天同巨门安星，该流年亦属不错。
- 限制：以上均为宽泛的推理思路，不能单独作为吉凶结论。实际判定仍须落到大限宫位的星曜组合，以及四化星冲起的情况，方可定吉凶。
- 本层只给出原则性规则，不作更细的展开分析。

## 四、流年命宫的定法

- 流年命宫即流年地支（太岁）所在的地支宫位。
- 例：流年地支为酉，则所有人的流年命宫都在酉宫。
- 流年命宫的定法对所有人相同，不因生月、生时而异；流月的起点则因人而异，见下节。

## 五、起斗君（定流月正月）

斗君即流月的正月所在宫。斗君以本人生月、生时为准推出，因此每人不同，且每年不同。同一流年内所有人的流年命宫相同，但流月命宫可分别落在不同宫位。

起斗君步骤：

1. 找到该流年地支（太岁）所在的地支宫位，作为起点。
2. 在该起点宫起"正月"。
3. 由此**逆时针**方向数月份：正月、二月、三月……一直数到本人的出生月为止，记该宫为甲宫。
4. 在甲宫起"子时"。
5. 由甲宫起**顺时针**方向数时辰：子时、丑时、寅时……一直数到本人的出生时辰为止。
6. 时辰落定之宫即为斗君所在宫。

方向校验：第一段（数月份）为逆行，第二段（数时辰）为顺行，两段方向相反，不得写反。

排算校验示例（流年地支为酉、生于三月、生于寅时）：

1. 酉宫起正月。
2. 逆行数月：酉宫为正月，申宫为二月，未宫为三月，生月落未宫。
3. 未宫起子时。
4. 顺行数时辰：未宫为子时，申宫为丑时，酉宫为寅时，生时落酉宫。
5. 斗君安在酉宫，即该年正月的流月命宫在酉宫。

斗君的作用范围：斗君只决定流月的起点，不改变流年命宫的位置。

## 六、流月、流日、流时的排布

- 流月：斗君所在宫即正月的流月命宫；此后每过一个月，流月命宫顺时针前进一宫。例：斗君在丑宫，则正月流月命宫在丑宫，二月在寅宫，依此类推。
- 流月排布不分阴阳男女：阴男、阳男、阴女、阳女皆按顺行处理。
- 流日：以当月流月命宫所在宫起初一，顺行十二宫，一日一宫，循环至当月最后一天为止。
- 流时：以当日流日所在宫起子时，顺布十二宫，一个时辰占一宫。
- 流月可用排盘程序排出；流日一层建议以人工推算为准。

## 七、流月四化与节气

两种口径并存，判定时须明确采用哪一种。

- 口径一：流月四化按农历月份切换，整个农历月统一使用该月月干的四化，不因节气交接而改变。
- 口径二（本体系采用）：流月四化随节气改变，交节之后即改用新月干起四化；但流月所在的宫位不因交节而改变。
- 换算示例：某年公历4月5日为清明，当日为农历二月十七，干支为庚辰月辛亥日。按本体系，该日的流月四化改用庚干（庚：太阳化禄、武曲化权、太阴化科、天同化忌），但流月命宫仍按原农历月份的排布宫位，不移动。
- 执行要点：四化随节气走，宫位随农历月走，两者分开处理，不得同步调整。

## 八、宫位重叠的解释方向

- 大限、流年的宫位移动与星曜互涉，一律解释为"外界环境来影响本人"，不解释为"本人去影响外界"。
- 具体表述：命宫代表本人的命，大限或流年命宫走到某宫，即该宫的人事与星曜性质来影响本人；本人处在这样的环境中并被环境所影响。
- 示例判定：流年命宫见天机化忌与擎羊同宫，断为该年环境使本人孤独、六亲缘分转薄、独居独处增多；研究学习方面易有思路不通、转不过弯的情况；天机化忌另主奔波出行、在外时间多；擎羊主竞争，易招纠纷与麻烦。
- 三层叠加时同样遵循此方向：原局宫位是本体，大限、流年宫位是加诸其上的环境条件。

## 九、三层体系的叠加

- 原局层：生年四化，作用于原局十二宫，为判定的本体层。
- 大限层：大限四化，作用于大限宫位及其所叠的原局宫位。
- 流年层：流年四化，作用于流年宫位及其所叠的原局、大限宫位。
- 同一宫位被两层或三层四化同时冲起时，须分层标明来源再合成结论，不得只取其中一层。
- 大限流年的宫位移动使星曜互涉，与三层四化的互相作用叠加后，构成判定中最复杂的一类变化，须逐层展开后再合成。

## 十、判定限制

1. 大限、流年吉凶必须由"原局重点 + 大限宫位星曜组合 + 四化冲起"三项共同得出，缺项时只给倾向性描述，不作定论。
2. 起限口径须先判定家庭与环境条件后选择，选定后全盘一致。
3. 流月四化口径须在输出中标明所采用的规则，避免与另一口径的结论混淆。
4. 斗君、流月、流日、流时的排布属于排盘规则，方向与起点固定，不随命造阴阳男女改变。
