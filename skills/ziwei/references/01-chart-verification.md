# 排盘与命盘核对

本文件只管“盘算得对不对、哪些信息足以支持哪一层判断”。盘面字段是计算结果，不是命运结论。

## 起盘输入

| 输入 | 用途 | 处理方式 |
|---|---|---|
| 公历出生年月日 | 定年、月、日及星曜排布 | 必需。用户给农历时须确认闰月并可靠换算 |
| 当地钟表时间 | 定命宫、身宫与时柱 | 必需。保留用户原始时间，不先手工改成真太阳时 |
| 性别 | 定部分排盘方向及有明确性别条件的规则 | 起完整盘必需；规则查询不需要 |
| 出生城市 | 查经纬度、时区并校正真太阳时 | 尽量到城市／县。只给省份时不得静默以省会代替 |
| 时间精度 | 判断是否要并盘 | 用户说“大约、左右、记不清”时视为低精度 |
| 目标日期与时间 | 计算大限、流年及更细层级 | 只在问运势或应期时需要 |

“算一下／看看这个”本身就是明确请求，默认做原局概览，不必再追问专题。只有缺少会改变排盘的输入时才追问。

## 真太阳时与时辰边界

必须同时保留并展示：用户输入的当地钟表时间、解析后的地点、真太阳时、校正分钟数、钟表时辰与排盘时辰是否不同。

按以下顺序处理：

1. 用出生地时区把当地钟表时间转为 UTC。
2. 结合经度和均时差得到真太阳时。
3. 以真太阳时确定地支时辰，再起盘。
4. 若真太阳时跨过子初而改变公历日期，排盘日期也随之改变。

出现任一情况时标记为“时辰待核”：

- 真太阳时距离最近时辰边界不超过 10 分钟；
- 校正前后跨了时辰；
- 用户说明出生时间只是约数，误差足以跨界；
- 地点只能解析到省份、同名地点或与用户所述不一致。

若时间记录精确且只是校正跨界，可说明依据后按真太阳时盘继续；若记录本身不精确，排相邻两盘，用命宫、身宫、主星组合及已发生的重要事实反验。不能任选一盘，也不能在盘未定时落到精细应期。

## 字段门槛

不同任务需要的字段不同，不采用“缺任一字段整盘作废”的一刀切规则。

| 任务 | 最少字段 | 缺失时 |
|---|---|---|
| 只排盘／核盘 | 输入资料、地点解析、真太阳时、四柱、十二宫 | 报出缺项，不作解释 |
| 原局骨架 | 十二宫与地支、正曜、庙旺、生年四化、命身、命财官迁 | 只封锁受影响部分 |
| 成格破格 | 原局骨架 + 相关辅煞、夹宫、三方四正 | 不给格局等级，只描述主星结构 |
| 专题 | 原局骨架 + 主宫、参看宫及相关辅煞 | 缩小到已有字段能支持的范围 |
| 大限／流年 | 原局骨架 + 大限区间 + 对应层宫位与四化 | 不给时间判断 |
| 流月／流日／流时 | 上述全部 + 目标时间及相应层数据 | 降到更宽时间窗口 |

## 必查一致性

- 四柱年干与生年四化表一致；时柱地支与排盘时辰一致。
- 十二人事宫各自只有一个地支宫，宫干宫支齐备。
- “命无正曜”只看十四正曜；长生、博士、将前、岁前诸星不算填宫正曜。
- 命宫三方四正必须是命宫、财帛、官禄、迁移，即本宫三合加对宫；不能用索引间隔三宫误取四墓。
- 身宫落宫、命主、身主、五行局如有输出，照录为盘面信息；没有本体系规则支持时不据此单独定吉凶。
- 运限盘须保留原局语义层，并明确大限／流年命宫叠到哪个原局宫位；不能只给一串流曜。

## 空宫与借星

空宫仍有人事宫位和地支环境。需要解释时借对宫正曜，再合看本宫辅煞与三方；借星不等于把对宫所有判断原样搬来。禁止由空宫推出“该六亲不存在”或“该类事情不会发生”。

## 工具输出异常

若工具字段互相矛盾：

1. 先核原始输入、时区、经纬度和真太阳时。
2. 再核四柱、宫位索引与四化表。
3. 能由确定规则重算的字段，注明后重算；不能确定的保留为缺项。
4. 不用下游断语反过来“证明”某个排盘字段一定正确。

出生地只用于时间和地点解析，不把城市本身附会成性格或命运象义。
