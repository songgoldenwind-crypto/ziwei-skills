# 排盘与命盘核对

## 起盘输入

| 输入项 | 必需性 | 作用 | 缺失或不确定时的后果 |
|---|---|---|---|
| 公历出生年、月、日 | 必需（与农历互为换算，有其一即可） | 定生年干支、月、日 | 不能起盘 |
| 农历出生年、月、日 | 必需（与公历互为换算，有其一即可） | 定生年干支、月、日 | 不能起盘 |
| 出生时辰 | 必需 | 定命宫与身宫落宫 | 不能起盘，禁止续断 |
| 性别 | 必需 | 男命与女命断法不同 | 格局成立与否、六亲吉凶不能定 |
| 出生地 | 仅用于校正时辰 | 与真太阳时配合，确定取哪一个时辰 | 时辰接近交界时取盘不稳 |
| 真太阳时 | 仅用于校正时辰 | 同上 | 同上 |
| 所问事项与当事人现实处境 | 必需 | 决定是否起断、取哪一宫为主 | 不得起断 |

出生地与真太阳时只作用于"取哪一个时辰"这一步，不进入后续任何取象。若时辰落在两时交界而无法唯一确定，本体系无确定取舍规则：须并列两盘，以当事人已发生的事实反验，不得任选其一续断。

## 十二人事宫位

每一人事宫必须标注其所落的十二地支宫位，二者一一对应，缺此对应关系即不能断。

| 人事宫 | 别名 | 本体系中已明确的判定用途 |
|---|---|---|
| 命宫 | — | 格局成破的首要判断处 |
| 兄弟宫 | — | 兄弟成就；亦为合作发展吉凶的参照宫 |
| 夫妻宫 | — | 配偶助力与刑克；男命与女命取义不同 |
| 子女宫 | — | 无附加规则 |
| 财帛宫 | — | 富贵判断的组合参照宫之一 |
| 疾厄宫 | — | 身体与精神受损处 |
| 迁移宫 | — | 在外、远行、海外谋生；亦可拱照命宫 |
| 奴仆宫 | — | 往来朋友的阅历与助力 |
| 事业宫 | 官禄宫 | 权柄、事业稳定性 |
| 田宅宫 | — | 财产积蓄与破耗 |
| 福德宫 | 福寿宫 | 福气、心态；福德宫差对寿命有影响 |
| 父母宫 | — | 父母身份地位与刑克；父母之间的感情 |

## 一张完整命盘必须具备的字段

| 字段 | 具体内容 | 判定层级 |
|---|---|---|
| 出生四柱 | 年柱、月柱、日柱、时柱；时柱随真太阳时，年干须与生年四化一致 | 阻断级 |
| 十二人事宫与地支宫的对应 | 十二宫各落何地支宫 | 阻断级 |
| 各宫宫干、宫支 | 宫位由天干与地支组合而成 | 阻断级 |
| 各宫正曜 | 含"命无正曜"这一判定结果本身 | 阻断级 |
| 庙旺利陷 | 每一正曜与可判庙陷的杂曜均须标注 | 阻断级 |
| 生年四化 | 化禄、化权、化科、化忌各落何星、何宫 | 阻断级 |
| 命宫三方四正 | 命、财帛、官禄、迁移，即本宫三合加对宫；禁止用四墓宫冒充 | 阻断级 |
| 辅佐杂曜 | 左辅、右弼、文昌、文曲、天魁、天钺、禄存、天马等辅佐曜；火星、铃星、擎羊、陀罗、地空、地劫等煞曜；天刑、天巫、天寿、天贵、天福、华盖、孤辰、寡宿、解神、截路空亡等杂曜 | 部分影响级 |
| 身宫 | 身宫落于哪一人事宫及其星系 | 部分影响级 |
| 命主、身主 | 起盘字段 | 部分影响级 |
| 五行局 | 起盘字段 | 部分影响级 |
| 各宫大限起讫年龄 | 每一宫所辖大限的起始与终止年龄 | 部分影响级 |
| 流曜依据 | 流年所在宫、流年四化、流曜（如流陀罗）所落宫；流月宫位与流月四化 | 部分影响级 |

阻断级字段缺其一即停止断盘，先补全再断。部分影响级字段缺失时，只封锁对应的判断范围：

| 缺失项 | 仍可断 | 不可断 |
|---|---|---|
| 身宫 | 命宫格局、各宫吉凶 | 事业稳定性、"禄逢冲破、吉处藏凶"一类结构 |
| 大限起讫年龄 | 原局 | 大限、流年、流月 |
| 流曜与流年流月四化 | 原局、大限 | 流年、流月吉凶与应期 |
| 辅佐杂曜 | 正曜层面的骨架 | 格局成破、刑克轻重、吉凶增减 |
| 五行局、命主、身主 | 全部星系层面判断 | 无——本体系未给出据此三项单独定吉凶的规则 |

排盘工具输出的杂曜落宫可能有误，起断前须逐项核对；若某杂曜落宫与排布规则冲突，以规则重定其宫，不以工具输出为准。

## 宫位与星曜的依存关系

- 宫位由天干与地支组合而成，天干在上，表示该宫的意向；地支在下，表示该宫的实际环境。
- 宫位不依托星曜而存在；星曜依托宫位而存在，星曜坐入宫位之后才产生影响力。
- 空宫仍然成立。长生十二神、将前十二神不计为填宫星曜，其存在不改变该宫"无正曜"的判定。
- 禁止由空宫推出"该六亲不存在"或"该类事不会发生"的结论。
- 空宫可借会对宫星曜及其四化；借会到化禄、化科者，该宫局面可判为较大。
- 宫干飞化可用于判断该宫的意向与所欲干涉之处，此项成立。但飞化不得脱离星曜与该宫本身的力量强弱单独使用：只看宫干飞化而不看星曜，多数情形会判错。
- 有意向且有行动，仍不直接决定结果。当双方力量对比悬殊时，弱势一方的意向与行动不产生其预期结果。

## 阴阳五行在命盘上的作用

星曜属"象"，是外在、可见的一面，为阳；排布规律、宫位排布、大限与流年的推移、四化的冲起属"数"，是内在、不可见的一面，为阴。断盘须两者合用。

对立统一的星曜配对：分工不同、落宫常不同，但相辅相成，同落一宫或会照时可加强彼此力量。

| 阳 | 阴 |
|---|---|
| 太阳 | 太阴 |
| 左辅 | 右弼 |
| 天魁 | 天钺 |
| 文昌 | 文曲 |

五行的方位与性质：

| 五行 | 方位 | 主要性质 |
|---|---|---|
| 土 | 中央 | 管理、协调其余四行；承载（受压力）；容纳（须忍受）；主被动 |
| 木 | 东 | 生长而须扎根，故依赖性强；主变化；主柔顺 |
| 火 | 南 | 热与光，发射性最强，可引申为传播、转移；具伤害性、破坏性 |
| 金 | 西 | 光泽显著故主张扬、不隐蔽；冷与硬并存；主计算 |
| 水 | 北 | 温柔 |

星曜五行对应：

| 星曜 | 五行 | 取用说明 |
|---|---|---|
| 紫微 | 阴土 | 北斗主宰，管理其余星曜；开创力、管理才能较强 |
| 天府 | 阳土 | 南斗主宰，观察力、协调力较强，善藏 |
| 天机、贪狼 | 木 | 变化性强；依赖性强 |
| 太阳 | 阳火 | 直接、外向、光明 |
| 火星 | 阳火 | 兼六煞之性 |
| 廉贞、铃星 | 阴火 | 发射、传播之性弱于阳火，不易被察觉 |
| 武曲 | 金 | 冷、硬、计算 |
| 七杀 | 本体属火，取用其阴金之性 | 断盘按阴金取象 |
| 天相 | 水 | 温柔 |

生克的使用口径与限制：

- 本体系以象义与组合为主，五行生克的说法并不常用。星曜由象义引申出的性质，往往与其五行本质关联不大。
- 禁止拿到命盘先看星曜的阴阳五行。
- 反例：太阳为阳火、文昌为阳金，按生克应为火克金，但太阳与文昌的组合一般主吉，无不良。故不得以星曜间五行生克直接定吉凶。
- 十二地支宫位各自的五行，以及星曜五行与宫位五行之间的生克如何增减象义强弱，本体系无确定规则。象义强弱一律以庙旺利陷、吉曜与煞忌的多少、格局成破、整体组合为准。

可以直接用于判定的五行结论（以下为已成立的具体条目，不作一般化推广）：

| 条件 | 结论 | 例外或限制 |
|---|---|---|
| 天府与廉贞同宫 | 廉贞的恶劣性质减轻：土能包容、控制阴火 | — |
| 天相与廉贞同宫 | 廉贞的破坏性、伤害性降低：水之温柔制阴火 | — |
| 太阳与火星同宫坐命 | 阳火叠阳火，直接、少谋略的缺点尤为明显，性格暴躁、难控情绪 | — |
| 火星、铃星同时落命宫三方四正 | 挫折、伤害较多；男命多在事业，女命多在感情 | 仅见其一者影响较弱，有时可忽略不计 |
| 天机坐命或贪狼坐命者创业 | 木之依赖性，宜与人合作，不宜单打独斗 | 兄弟宫极不吉，或大限极差时，合作亦吃亏受损 |
| 五行土之被动性质 | 须有辅佐与外界支持方能化被动为主动 | 借不到外力且本人才能不足者，成就减等 |
