# 十四正曜与禄存

按当前主链只查涉及的星曜段落，不默认通读或复述全表。下文“必、刑、克、富贵”等为传统规则中的内部权重词，不是现实事实保证；输出时须结合宫位、三方、四化与现代处境，改写为可理解的行为模式、资源条件和风险倾向。涉及疾病、死亡、犯罪、品行或婚姻事件的条目只可作为待复核象，不得直接对用户下事实结论。

## 禄存

不属十四正曜，但为禄星之一，须先于正曜取用。三财星为武曲、太阴、天府；两禄星为禄存、化禄。禄主正当所得，为养命之源；财星兼管不正当所得。财星化禄（武曲化禄、太阴化禄）为以财生禄、禄又生财，最利财运。

- 五行阴土，性质保守、稳定、被动，主孤，兼爵禄（爵为地位、禄为财富），可论寿基，有解厄制化之功。
- 按生年天干临官位安星，只入寅、卯、巳、午、申、酉、亥、子八宫，永不入辰戌丑未（辰戌为天罗地网限制星曜活动，丑未气息混沌多变，皆与禄存保守之性相违）。天魁、天钺自丑未起、永不入辰戌，与禄存永无同宫机会。
- 前后二宫永为擎羊、陀罗（羊陀夹）。夹力可为护禄，亦可转为剥削、掠夺，且方向双向：既可自己夺人之财，亦可自身之财被夺，须视同宫星曜与所落宫位定。
- 性质被动，在组合中受同宫正曜或煞星支配：七杀同宫则禄由七杀而得；火铃空劫同宫则主以技艺求正当收入。
- 喜天马同宫或对宫会照成禄马交驰，主奔走生财，入命宫、财帛宫、田宅宫、迁移宫皆吉，田宅宫见之可在外地置产；喜化禄同宫、三方会照或六合宫有化禄（明禄暗禄）；与天巫同宫、三方四正有吉星吉化而无煞忌，主可继承或唾手可得之财产。
- 忌与地空、地劫同宫（贵气财气俱损）；一般忌与化忌同宫，主丧失稳定性而多凶。

| 武曲 | 孤而势利，重私利，易损人利己 |
| 天府 | 福禄厚重但易成守财奴，极重金钱、行为现实保守，一般不损人 |
| 紫微、太阳、七杀 | 一般不受攻击排挤，但羊陀夹宫仍限制命运、小人多 |
| 破军或煞星 | 理财转趋激进，不再以保守论 |

| 宫位 | 判断要点 |
|---|---|
| 命宫、身宫 | 理财保守，冲击力不强，宜安稳工作；易犯小人 |
| 财帛宫、田宅宫 | 最宜。会吉星吉化且三方四正无火铃空劫，必主生活富裕，格局大者大富大贵 |
| 事业宫 | 增强事业稳定性，利上班受薪、政府与大型机构，可因积累资历晋升 |
| 迁移宫 | 不见煞忌则出门得财，宜外地发展或多外出多交际之职；女命三方四正吉利者可嫁富裕之夫（迁移宫可作夫妻宫之财帛宫解） |
| 夫妻宫 | 正曜庙旺兼会吉星吉化，主配偶赚钱能力强或经济上助己；煞忌多则禄存失稳，易离婚 |
| 子女宫 | 空宫而禄存独坐主子女数少、晚得子；会吉化则得子后经济好转；会煞忌则为子女花销大 |
| 兄弟宫、奴仆宫 | 会化禄、辅弼、昌曲、魁钺且正曜吉利，可因友属或合伙得财；禄存落奴仆宫则擎羊必在迁移宫冲命，一生奔波不安稳 |
| 福德宫 | 内心有孤独感；照入财帛宫多利财运。化禄在财帛宫又有吉星吉化者能享金钱之乐、败而不馁；与空劫火铃同宫且财帛宫不吉者缺乏安全感、因钱焦虑自卑 |
| 疾厄宫 | 宜上班受薪（疾厄与父母相对）；阴土主肠胃消化问题，兼有结石之虞；少年多灾，成年后转好；遇灾病多伴破财 |
| 六亲宫位通论 | 有解厄制化能力，不主刑克；但主孤，对感情与六亲缘分略有不利。与火铃空劫同宫，主因亲属、下属、朋友有经济纠纷或破财 |

- 阳梁昌禄：命宫安卯，三方四正会齐太阳、天梁、文昌、禄存（或化禄）且不见煞忌，主竞争得胜、名位双收，宜政界或企业领导；既无禄存又无化禄者层次明显降低。大限、流年之命宫或事业宫成此结构而不见煞忌，主学业事业大进。太阳天梁在卯安命而三方四正见煞忌者，转为武职、商业或技术出身；煞星与吉星并见则技术水平高、可因技艺扬名。
- 通例与例外：一切正曜皆喜会照禄存、化禄以增强正面性质；但同宫或自身化禄多带缺点，不如三方会照。如命宫、福德宫贪狼化禄，虽增悟性与财运，却增人生享受、不能吃苦，反致事业成就不大。羊陀夹忌为败局，主要验于命宫（禄存与化忌同宫被羊陀夹，难守财、易败）；同一结构落财帛宫则不必作凶论，亦有富贵者。寿命不由禄存一星决定，须合参命宫、身宫、福德宫、疾厄宫。

## 天府

- 五行阳土，南斗主宰，财帛主兼田宅主，为禄存之仓库。性质稳定、欠缺变化，主吸收、积累、发展与包容；发展能力强而发明能力弱，守成大于创业，宜在既有基础上提升。
- 格局大小以吉星多寡定：见左辅、右弼、天魁、天钺、化禄、禄存、化权、化科、文昌、文曲、三台、八座、台辅、封诰为格局大，包容心大；无此等吉星吉化则格局小，再受煞忌、天姚侵害易成奸诈虚浮、想法不切实际（论心性须命宫加身宫、福德宫合参）。
- 抗煞力强：能制羊陀、化火铃为福，不惧羊陀火铃同宫，煞星不多时其害可忽略。但极畏空亡：地空主暗中吸蚀（损失不知何时、由何人），地劫主明面劫夺（可知何时何地由何人），旬中空亡、截路空亡影响亦大，天空影响较小。
- 与空劫或旬中空亡、截路空亡同宫坐命，或坐命而三方会照空劫（仅三方会照截路、旬中空亡无影响），必感空虚，有孤辰、寡宿更重；三方有辅弼、魁钺、昌曲、双禄、化权化科者成就仍大且富创意，但精神孤独苦闷。受空星影响多近宗教、哲学、命理、风水，组合佳者可于此成就。七杀坐命而命宫三方四正或迁移宫天府三方四正遇空劫，亦主空虚、对世俗无兴趣。
- 贵气于天魁、天钺、龙池、凤阁、三台、八座显；领导力于左辅、右弼显；辅弼齐会可提高地位、增开创力与权威、使局面扩大并减辛劳。喜与化科同宫于命宫、身宫（增聪明才智，利事业表现），三方会照次之。
- 落宫：以戌宫廉贞天府、寅宫紫微天府较佳，午宫武曲天府亦佳（午优于子，子宫较浮荡、心思游移、眼光不远）。其余宫位若得辅弼增开创力、双禄增财气亦能成事；再得魁钺则事业有特殊机会而骤进。
- 时序：宜少壮积蓄、三十后发力，少有年少富贵者。例外：行破军或贪狼大限而三方遇吉星吉化，可年轻突发；天府与地空同宫坐命而三合遇吉星吉化，亦可因投资横发，但横发易致懒惰贪逸，长远非吉。另一缺点为达成目标后感严重空虚而停止进取。

| 宫位 | 判断要点 |
|---|---|
| 财帛宫 | 吉多无煞为理财能手，财运稳定，大限不吉亦不致倾家（须合参命宫、身宫） |
| 田宅宫 | 多主有房产继承或直接获产，本人能力不强亦能守业；见吉星吉化多主出身富贵、可继承多套。忌见擎羊（产权明争暗斗、置产不顺或较晚、家人纠纷），擎羊再兼会其余煞忌易因产权诉讼 |
| 夫妻宫 | 配偶勤俭厚道并助己经济；与禄存或武曲同宫主由配偶理财、配偶节约。女命贪狼坐命者宜配体健肥壮之夫，男命贪狼坐命者宜娶端庄勤俭之妻 |
| 事业宫 | 天府坐命则天相必在事业宫，天相会吉越多则天府权力越大 |
| 迁移宫 | 不见煞即以吉论，主出门得财、出门遇贵，宜外地发展、适应力强；见煞忌不作此论 |
| 兄弟宫、奴仆宫 | 有助力但不大；须会辅弼魁钺且三方四正不见煞忌，助力方增 |
| 福德宫 | 见吉星吉化则内心安稳、适应力强；与禄存同宫能享赚钱之乐、爱理财；喜化科（减烦躁）、化权（增上进与财欲）。三方四正见擎羊、天刑、火铃主压力大缺安全感；空劫同宫主空虚无方向、无事奔忙，女命兼主婚姻感情不顺；羊陀火铃化忌会照亦主孤虚，精神难满足者易沾赌博等不良嗜好而耗财。只有一二煞星仍以吉论 |
| 父母宫 | 多主父母双全、不主刑克，稍见吉星即相处和睦有助力；煞忌多则无助力且易因金钱生纠纷 |
| 子女宫 | 见吉星吉化主子女多、感情好；见煞忌易因子女破财，甚至生败家子 |
| 疾厄宫 | 天府在疾厄则命宫必天梁，须以命宫天梁所会星曜定身体状况；天府、天梁皆解厄，不主大灾，纵有终可化解。阳土主肠胃（消化不良、胃炎、胃溃疡），与空劫同宫更验；三合武曲化忌易因病破财或开刀 |

- 通例：天府以不与空劫同宫为佳，任何宫位皆多少带破财性质；羊陀火铃之害有限，煞少时可略。天府为财星，在财帛宫、田宅宫主富厚，但以见吉星吉化为准。论财运除命宫、财帛宫、田宅宫外，须加兄弟宫、奴仆宫、迁移宫合参——天府兼田宅主，与诸煞同宫坐命会损人际关系而间接损财运。天府若与空亡同宫守命，家庭状况难美满，严重程度须并观田宅宫、父母宫、夫妻宫、兄弟宫。

## 天相

- 五行阳水，化气为印，代表权力而非权力中心（权力中心唯紫微）。主辅助力与证明力，带庄重、官方、程序色彩，兼有传承性质，属阳水而略含桃花。为司爵之宿、事业宫之主曜，落事业宫则吉者倍吉、凶者倍凶。
- 性格判定：多啰嗦、爱管闲事；欠决断力与魄力、好征询他人意见，男命多有辅佐他人之想，宜居二把手（非政界而统领小团队则可为主）。注重仪表修饰以求体面庄重（与贪狼修饰以求吸引眼球、奇装异服者不同）。与辅弼同宫者忠厚老实、可统御下属、得人支持，但开拓力不强、更宜守业。
- 首要判法为看两夹，重于三方四正。天相前后永被巨门、天梁所夹，绝无例外。
  - 财荫夹印：巨门宫位化禄（以巨门本身化禄，或巨门与禄存同宫为确），后一宫天梁发挥荫星保护之性。最吉。
  - 刑忌夹印：巨门宫位化忌（以巨门本身化忌为确），天梁转发刑星之性克害天相，三方又无吉星吉化解救者，主厄运，煞重有牢狱之灾。
  - 只观巨门所在宫位，天梁宫位情形不重要：巨门无化禄而仅同宫他曜化禄（如天机化禄、太阳化禄、天同化禄），益处不大可略；巨门无化忌而仅同宫他曜化忌，害亦不大，一般不作刑忌夹印论。
- 夹辅与夹煞：喜成对吉星夹（左辅右弼、文昌文曲夹丑未天相；天魁天钺夹辰戌紫微天相）。畏成对煞星夹（火铃、空劫、羊陀），四煞来夹守命则局势恶劣、一生挫折多且难得外助。财荫夹印以同宫更有辅弼、魁钺、昌曲、禄存为最好；无吉星而反见煞忌则吉性减弱。天相与擎羊同宫而邻宫巨门与禄存同宫，仍属财荫夹印，但必带竞争、纠纷、争夺，单颗擎羊之害有限。
- 财荫夹印以坐命宫、事业宫为最好，财帛宫、夫妻宫、田宅宫稍次；落疾厄宫、奴仆宫、子女宫对本人无多少好处，此时重点改研究巨门化禄对全局的影响。事业宫成财荫夹印者命宫必天府，主事业得外助且巨门化禄必在田宅宫，兼利财运、多主多套房产（田宅宫巨门化禄不见煞主家人齐心共创财富）。父母宫成财荫夹印者命宫必巨门，属自力创业结构，父母助力不大。
- 天相化忌（庚干）：助力下降，不利学业与官运；命宫、事业宫见之多难考取功名、考公不顺，甚有虽入学而无法毕业者。流月天相化忌多主证件、磁卡失效。田宅宫天相而庚年生人较难有祖产。
- 逢府看相、逢相看府：天府与天相永成三合会照，为一组对星，须并观各自同宫与会照之星。天相喜会紫微以增彼此力量，不会紫微则将助力作用于其余正曜。天相永与破军相冲，论天相须计破军影响。天府坐命而三合得天相之助，一般不必忧婚姻、子息（命宫三方四正煞多者不以此论）。

| 宫位 | 判断要点 |
|---|---|
| 财帛宫 | 总体吉，以见吉星吉化为佳，主财运顺遂、赚钱容易，格局大者可大富；见煞忌则财气受损，宜以技术求财。成财荫夹印者资金流动顺畅、赚钱得人助，少有缺钱之时（须配合大限流年） |
| 事业宫 | 以吉论，主有辅佐之才、能助人亦能得人助与认可。辅弼增权威、扩局面；魁钺增贵气、得贵人并能与层次高者往来，兼主处事公道、能为人排解纠纷；昌曲、化科同宫宜文职教育；与武曲同宫可为武职。三方四正会煞忌则事业多波折、局面变小、功名难成 |
| 夫妻宫 | 对男命较吉，煞少即主妻能助己；主亲上加亲，或与旧同学、旧友、旧情人重逢而成婚（流年夫妻宫见天相亦主旧识重逢或旧情复燃，能否成婚须合参大限与原局）。不宜见天姚、红鸾、左辅、右弼（婚后易有第三者），最好不与武曲同宫（妻强势）；落陷则助力普通。成财荫夹印者命宫必七杀，利男命而于女命益处很小 |
| 子女宫 | 成财荫夹印主能有子但迟得，多在三十岁后，三十前多只有女。三方四正吉多则子女聪明善学听话有富贵；煞忌众多则较难有子或子难养 |
| 田宅宫 | 入庙主得祖产；会煞多或成刑忌夹印则与祖产缘薄，须自力买房 |
| 福德宫 | 喜吉星吉化，尤喜辅弼、禄存、化禄。得辅弼魁钺拱凑而煞少者内心正派、有责任感、能急人之难；无吉化而被煞忌侵害则心态不正、无责任感、三分钟热度；见破军化禄冲照主心思变化快、常改主意；煞忌多者对女命婚姻极为不利，对男命影响稍小 |
| 父母宫、兄弟宫、奴仆宫 | 多主能帮扶自己，以入庙、不见煞忌为佳。天相本质为吉，不主刑克，即使不能助己一般亦无大克害，除非会羊陀、天刑、火铃、武曲化忌、廉贞化忌 |
| 迁移宫 | 成财荫夹印者利人际、宜外地发展、在外得人支持，亦利在外地考公、考试、考证；再得辅弼魁钺拱照则兼主社会地位、受人尊重。成刑忌夹印则不利外地考试考证。只要煞少且非刑忌夹印，皆可外出发展 |

- 男女差异：女命天相坐命宫或身宫而不见煞，多主貌美、性温婉、能匡扶丈夫；与武曲同宫则不然，易凌驾于夫。女命天相坐命得辅弼相会而福德宫、夫妻宫又佳者有旺夫运。天府、天相坐命之女多乐为家庭付出，子贵夫贤比例较高，但须并看子女宫、夫妻宫，不可仅凭命宫断之。

## 紫微

- 五行阴土，北斗主曜，权力中心，事业宫之主曜。性好享受，本质风流不专情，唯我独尊、喜驾驭他人，有解厄制化之力。紫微、武曲、廉贞永成三合会照：紫微为权力中心，廉贞为权力延伸（属下、基层），武曲为资金，一荣俱荣一损俱损——武曲化忌则紫微权威受损、地位下滑，廉贞亦受害。

  - 百官朝拱——会左辅、右弼、文昌、文曲、天魁、天钺、三台、八座、龙池、凤阁、恩光、天贵、台辅、封诰、天官、天福、禄存、天马（共十八曜；天才、天寿主增个人能力，不属外力，不入此列）。能将权力发挥至极。

## 廉贞

- 五行阴火，事业宫之主曜（官禄主），同时为副桃花主，故本质存在理智与情感之冲突：理智一面主忠于职守、执行力强；情感一面主感情丰富、易因感情误事，亦主人际关系网中的亲疏结党、因人情而违规。本身带煞气，有意外事故之性；对应人体血液。
- 取用规则（判断发挥官禄主还是副桃花主）：

- 抗煞与灾厄：六煞之中较不怕空劫——廉贞与空劫同宫坐命而无其余煞忌，不主意外事故，反主有创造力、思维与众不同。但与羊陀火铃、天刑、化忌相会则有脓血病灾、官司、坐牢乃至意外死亡之可能（化囚为杀）；官非结构以廉贞、七杀、擎羊、天刑最危险；脓血病灾以廉贞化忌为验。例外：廉贞化忌亦可为女子生产之象（有痛苦风险，且关乎血液、血脉传承）。六亲宫位见此类结构而有化忌冲起者，可能有亲人因意外事故离世。廉贞三合必遇武曲，若武曲与羊陀同宫则因金钱生纠纷；流年行至廉贞之位而三合遇武曲羊陀者，易因钱财与人冲突，煞重则涉讼。

## 天梁

- 五行阳土，南斗第二星，司寿，化气为荫，主福寿，为父母宫之主曜。兼具荫星与刑星双重性：荫主照顾、帮助、庇佑、保护；刑主惩罚、伤害。领导力强、权力欲强，习惯照顾并指挥他人、好向人传授经验；原则性强、责任心强、执行力好，同时又有随便、懒散、无所谓的一面。与宗教、哲学、术数关系密切。
- 逢凶化吉机制（关键，不可简化）：必先有凶兆出现，其后方能化险为夷，非遇凶即刻化吉；多数须经伤痛、苦难、险阻、虚惊之后境遇才扭转。故天梁坐命者虽多机缘巧合、逢凶化吉之事，亦比常人遭受更多苦难折磨，因而多研究宗教、术数以求解脱。入庙且三方四正煞忌少者，遇险时所经困苦少、化解快；落陷或煞忌多者须历诸多波折痛苦方渐安。寅宫天梁与天同同宫为荫福聚，最能逢凶化吉；申宫天梁落陷，虽仍有解厄之能但力量弱于寅宫。其余正曜坐命而大限、流年行至天同天梁之宫，亦能逢凶化吉。
- 与天相比较：二者皆主帮助、皆带服务大众性质。天梁之助多来自长辈、亲友及年长者，带庇佑保护，且多出现于危难之际（此为天梁独有），覆盖面较窄而专业性强；天相之助宽泛，亲属与陌生人之相助皆属之，覆盖面广而专业性淡。武曲、天梁坐迁移宫而组合优良者易成富商。

## 天同

- 五行阳水，福星，福德宫之主曜。其福偏重精神层面，物质上仅属普通；唯天同化禄，或与其余化禄之曜相会，或与禄存相会，物质享受方增，可称福禄双至。判福之标准在家业、后人、身体三者俱全；富而家不美满、后人不昌或身体不佳者，只可称有享受，不可称有福。

- 男命：辰戌丑未安命得吉星拱凑主事业有成；入庙再会左辅右弼、天魁天钺，主口才好、组织力强，可从政掌权，不从政亦可创业。贪狼型从政者与紫微、太阳、天梁型不同——后者带贵气而自视较高，贪狼则能礼贤下士、善于伪装、应对复杂人际，少陷骄满。
- 女命：不宜身宫见七杀、破军，加强杀破狼动荡性质而人生多波折；再见桃花星多者恐沦落风尘。

## 七杀

- 带杀气与煞气。守命者不论成就大小，一生必有一段痛苦经历，多数人有一次重大失败：为官者遭诬陷打压甚至丢官，为商者突然破败，受薪者亦遭变故而事业停滞；少数人仅表现为某段时期运气极坏、诸事不顺、家庭不和。
- 庙旺极重要：寅申入庙，子午辰戌丑未居旺，巳亥为平，卯酉落陷（酉略好于卯）。陷地守命凶险灾祸必多。庙旺守命者，纵无吉星吉化，只要敢于拼搏再交一步好运亦能成事。
- 抗煞：抗煞力强。煞星能加强其气魄，庙旺七杀较不怕煞星冲破，因其本无先天富贵之气、靠自力取富贵。评断时须重点看"气魄"而非单看吉煞多寡。

## 破军

- 化气曰耗，主消耗、破坏、动荡、波折、困难，变动色彩极强，即使紫微同宫亦不消失。判断核心在于这种破坏是越变越好还是越变越坏，任何组合都不会一成不变。
- 庙旺极重要（与太阳、太阴、七杀、天同、天梁同列；天府、天相则以组合为重）：子午未入庙，辰戌丑居旺，寅申卯酉落陷，巳亥居平。喜入之宫为子午（对拱廉贞天相）、丑未（紫微同宫）、辰戌（独坐）。
- 抗煞：庙旺者与七杀同，纵遇煞亦可富贵，较不怕煞星冲破。但对禄的依赖强于七杀——三方四正无禄存、化禄，则变动中所得经济利益大减，人生更辛苦操劳。
- 喜忌：喜紫微、禄存、化禄、天魁天钺、左辅右弼。不宜文昌文曲（武职之星与斯文气质不合，上进心与决断力下降），尤畏与文昌化忌、文曲化忌同宫。例外：寅宫、卯宫破军与昌曲同宫，若无其余煞星捣乱且大运佳，可得富贵。庚年生人破军坐命受天相化忌冲射，外助减少，多靠自力。

## 太阳

- 四大主星之一（紫微、天府、太阳、太阴），白天之主，永在紫微的子女宫，故主贵而不主权——地位高而实权色彩远不如紫微。为事业宫主星。
- 六项基本性质：一、发射性强，主付出与照顾且不求回报，性善良；二、为动星；三、为贵星，地位高、气质骄傲，可代表贵人；四、为事业宫主，象征前途，可代表官府，影响事业发展；五、正大光明、正派阳刚；六、易惹是非纠纷、易被人埋怨。
- 应用限制：以上性质须依所落宫位解读，不可生搬硬套。坐命身者必有骄傲本质、不愿从事低贱工作、渴望被尊重，此条恒成立；但"奔波变动多"不能仅凭太阳坐命断定，须综合整体组合。
- 昼夜：寅卯辰巳午未时生为昼生，申酉戌亥子丑时生为夜生。喜昼生，夜生者力弱、命运发展乏力。此项须看，出生天气、季节之类不再细分。

## 太阴

- 癸水，与太阳为对星，四大主星之一，夜晚之主。主富、主内敛、主计谋规划，为财星，含投资理财、经商赚钱之义；亦主感情与情商。为田宅宫主星。
- 判断次第：先看庙旺平陷，次看命宫三方四正组合，再看吉化。但庙旺影响不可看得过重——庙旺坐命可能只是小职员，落陷坐命亦可能富豪。女命例外：太阴庙旺坐命基本都优于落陷，落陷者刑克父母且本人婚姻必有问题。
- 核心判据是才能高低："品""德"归太阳，"学""才"归太阴。他星才能不足尚可以其余优点弥补，唯太阴守命者才能不足则难有大成。
- 五项缺点：拼搏心弱、不够努力；虽为主星但领导力弱、缺乏气魄；吉少而煞星拱凑则所拟计划糟糕、屡屡失策；癸水主感情，煞忌多者情商低；重感情、易被情欲影响。横向比较：论努力不如武曲、七杀；论领导力不如紫微、天府；论白手创业不如天同、巨门。
- 喜忌：庙旺喜文昌文曲与化科，可借读书、考学、写作展现才能；落陷则加昌曲反使气质更柔弱，落陷更喜左辅右弼增其助力。遇禄存、化禄、天马、左辅右弼、天魁天钺者有商业头脑、财运佳，纵无昌曲化科、学历不高，亦可凭赚钱展现才能。太阴财气强而贵气弱，欲得高社会地位须入庙并遇化权及左辅右弼使局面变大，否则只是清贵、权力不大。太阴化忌在很多情形下都不算凶。

## 天机

- 乙木，谋臣之星，主智力、计谋、脑筋、思维，兼主机器、机会、变动——机会总在变动中出现。安星上天机永在紫微的兄弟宫，紫微永在天机的父母宫。木之依赖性最强，故判断两条：本人才华智慧高低，以及所处环境（大运）如何。
- 喜忌：最宜三方四正见文昌文曲、天才、化科、龙池凤阁以增智慧，分析、判断、学习能力皆强，不被煞忌冲破即可成才智高超之人或掌握专业技能。喜天魁天钺增贵人运与机遇。一般不宜命宫与左辅右弼同宫——谋臣只需遇明主，不需下属支持与实权，天机领导力弱，辅弼好处不大反成拖累；例外：天机天梁坐命时辅弼可强化天梁领导力，天机太阴、天机巨门见辅弼稍有好处，但远不及紫微、天府得辅弼之利。喜父母宫紫微得左辅右弼同宫或朝拱，主得父母、长辈、师长、领导提携甚多。最佳配置为：命宫三方四正会科文星、天魁天钺、化禄禄存、龙池凤阁、恩光天贵，同时父母宫紫微得左辅右弼。

- 环境依赖：天机坐命大运走势极关键。能力强而运不至者难有出头之日；能力强再遇赏识则可施展抱负。

| 田宅 | 与太阴、天梁同宫较吉，可有房产继承或置产时得亲友相助、过程顺利；与巨门同宫或独坐则较不利，多靠个人努力购置（非绝对，须看整体）。天机主变动，故房产多变，即使购置也不能立即入住或住不长久，往往须三五年后方能长住 |
| 福德 | 性质吉利，愿动脑、想法多、思维灵动。女命福德宫天机不宜见煞，天机本有孤独、变动之质，与煞同宫对婚姻感情极为不利。化忌不表示愚蠢，但反应较慢、显木讷；化禄、化权、化科均增智慧、反应快。与陀罗、阴煞同宫者较精明、带小伎俩，命宫格局一般则不主大智慧大成就，命宫格局大时方带来更大好处 |
| 六亲宫 | 夫妻、父母、子女、兄弟、奴仆皆有不利性质，因天机主变动、奔波、远行，使关系疏离。兄弟、奴仆宫不见煞忌者，仍可自知己、朋友、下属处获得一些好处，至少是精神支持或意见建议。父母宫化权主父母管教严厉、干涉生活；兄弟、奴仆宫化忌不宜与人合作，主意见不统一；子女宫化忌主易与子女分开、子女令人操心。六亲宫化禄再见天马、天魁天钺、左辅右弼者，该宫位之人适合在外地生财，或从事奔走生财、为人谋划的工作 |
| 夫妻 | 最怕天机化忌；再见火铃、羊陀、空劫、天马、解神、孤辰、寡宿、破碎者离异可能极大，即使不离异也长期分居。六亲宫天机化忌皆带分离意味 |

- 冲破与大限互涉：天机坐命宫内虽有天才、文曲等吉星，若迁移宫有巨门、擎羊、铃星冲破，格局大幅减色，不可只凭本宫吉星断其聪慧成就。天机坐命者行至太阳所在宫位多能得较大发展——天机本身缺贵气，太阳为贵星可补其不足并提供贵人运。

## 巨门

- 本体属阴水兼阴金（口属水，口中藏齿属金），而多以土为用——主通道、管道、容纳与藏（口鼻耳目眶、毛孔、下水道、隧道、矿井、水管、电线管皆是）。土之用亦含创造与创业：巨门化权、化禄善创业，见吉可得富贵。
- 阴水本性主阻碍、遮蔽、阴暗、不明朗、冷漠、阴寒，故亦主口舌是非、阻碍、挫折、困难，多数情况下作煞星使用。但阻碍挫折未必是坏事，事业成功前多先有困难。
- 联动规则：巨门无论落于何宫，都会以三方四正直接相会或借星安宫间接相会的方式影响天机、天同。巨门坐命必与天同相会，天同主白手兴家、巨门主阻碍困难，二者组合即含创业发家之义。

| 会照条件 | 判断 |
|---|---|
| 会天机化禄 | 变动机会多、带来经济好转，兼职副业增多 |
| 会天同化禄兼天机化权 | 可能有突然转机，吃苦后得幸福生活 |
| 会天机化科 | 知名度提高，但口舌是非同时增多。注意：三方四正有天机化科则巨门必化忌 |
| 会天同化忌 | 享受降低，但此时巨门可能与太阳化禄相会，贵人运增强、利外地发展；若降低生活享受而转向事业突破，反主进步 |
| 会天机化忌 | 思虑重、劳心劳力，带孤独色彩，缺乏转变良机或有机会而未把握；多宜上班、为他人谋划，若要创业须兼看大运流年 |

- 喜忌：最喜化权、化禄、禄存在三方四正相会——化权增上进心、决断力、意志与魄力，化禄与禄存增财，二者皆使口才加强。自身不化权化禄者，三方四正得天机、天同、太阳的吉化照射亦有利。喜文昌文曲，增才智与应变、口才更好，但巨门与昌曲坐命者意志偏薄弱、难坚守原则。左辅右弼、天魁天钺有一定好处。较不宜火星铃星同宫，本已主障碍挫折，再加火铃则挫折增多、人生难美满。遇擎羊、陀罗、天刑则口舌争端增加、须费神费力解决。巨门擎羊同宫可取象暗器，阴险、可突然发难、杀伤力强，但不主贵，命宫身宫见之宜以求财为主，不宜追求社会地位与外界认可，亦不利求学；巨门陀罗同宫主说话刻薄，杀伤力弱于巨门擎羊。
- 最佳配置：以自身化权、化禄为上，其次见天同化禄、天机化权；再会文昌化科构成三奇会照，富贵不小。遇天机化禄最好安命卯宫，双禄同宫主富贵；其余宫位遇天机化禄未必吉，因此时必有太阴化忌冲射事业宫。
- 合参：巨门坐命夫妻宫永远是太阴，太阴兼具感情色彩与财星性质，夫妻宫好坏对命运影响很大。

| 落宫 | 判断 |
|---|---|
| 子、午 | 石中隐玉，须三方四正见吉星而无煞方入格。对男命十分有利，女命较一般。个人能力未必强，但对事业认真积极、善于动脑、聪明外露，工作上能超常发挥；男命早年辛苦，三十岁后渐发。丁年生人巨门化忌安命午宫亦入格，子宫次之。女命成此格宜安命子宫，夫妻宫太阴在旺地，婚姻稍好于午宫 |
| 丑、未 | 天同巨门，以见吉星吉化为佳：得化权、化禄、禄存、左辅右弼、文昌文曲皆主有才能，见天魁天钺效果较一般。即使见煞，一生中也总能获一两次大好良机、可短期内大发展；但格局不佳或大运不吉则势头难保，几年后即衰。巨门化禄者财气旺兼有贵气，可创业、经商或任公职；天同化禄则财气逊色，较利上班。天同与巨门化权同宫可创业或任企业管理者，但此组合又与擎羊同宫或擎羊在对宫，不算上格，易遭暗器式攻击与是非纠纷。此局夫妻宫为太阴独坐，取象井中月：无论男女、无论丑未安命，都易有镜花水月的感情，看似美好而本质虚幻，纵丑宫太阴入庙亦不主大吉；宜将精力集中于事业、看淡感情 |
| 卯、酉 | 天机巨门，事业宫借入太阳太阴，迁移宫为空宫，财帛宫为天同。主聪明、口才佳、反应快，稍交好运即可快速发展；但主变动，一生运势不安稳，酉宫尤须提防事业倾覆，卯宫变动小于酉宫。以三方四正见吉星吉化为佳；稍见一两颗煞星一般不甚要紧。命宫巨门遇擎羊、天刑，或巨门化忌，可从事律师、牙医、管道疏通类工作 |
| 辰、戌 | 落陷，负面性质较重。戌宫能会照入庙太阳，怨气与压抑感减轻；辰宫则多怨言、不满足、嫉妒、看人不顺眼、厌他人出风头、好压过别人。宜辛年生人，若迁移宫遇文昌化忌称变景，主吉不主凶——辰戌对宫必有天同，天同为福星不怕化忌同宫且能减弱化忌威力；但三方四正煞星太多仍作破格，不主成就大。此条只利男命，女命较普通 |
| 巳、亥 | 入庙，常有身材高大或肥胖者。福德宫为丑未天梁，男命较有正义感、常看不惯他人所为、易生口舌是非，巨门化忌者更甚，宜谨言慎行、勿随意指责他人。见吉星吉化多者能力强、有恒心毅力；吉少且太阳亦落陷者做事虎头蛇尾、治学不深。巨门在巳化忌必与陀罗同宫，主管不住嘴、说话难听、易得罪人、易泄露机密、多口舌；在亥化忌情况稍好，仍宜少言 |

- 男女差异：巨门坐命多少带坎坷、波折、忙碌之性，男命多表现在事业不顺，女命多表现在婚姻感情不如意，故各宫位巨门坐命的女命一般不如男命；女命宜避免早恋，须提防居心不良者以免受打击。

| 宫位 | 判断 |

| 六亲宫 | 与该宫位之人不和睦、易争吵、有口舌是非，感情不深厚。但遇吉星吉化则反主该宫位之人事业有成：兄弟宫巨门化禄、化权主兄弟有才华成就；夫妻宫、父母宫化禄化权主配偶、父母有才华、创业有成 |
