# 紫微斗数宫位体系判定规则

## 一、两套宫位的性质与总原则

命盘同时存在两套宫位，必须叠合使用。

| 项目 | 人事宫位 | 地支宫位 |
|---|---|---|
| 构成 | 命宫、兄弟宫、夫妻宫、子女宫、财帛宫、疾厄宫、迁移宫、奴仆宫、事业宫、田宅宫、福德宫、父母宫（另有身宫） | 子丑寅卯辰巳午未申酉戌亥 |
| 阴阳 | 属阴 | 属阳 |
| 显隐 | 隐、虚拟 | 显、实际 |
| 动静 | 排序固定但整盘可移动（大限十年一移，流年一年一移） | 位置固定不动 |

判定用途：
- 凡问"是什么事、关涉哪一类人"，取人事宫位定性；凡问"落在什么实际环境、象义具体化成什么东西"，取地支宫位定形。
- 人事宫位必与地支宫位结合，二者互相影响；同一组星曜配同一人事宫位，落入不同地支宫位，象义即有差别。
- 人事宫位可移动，所以运限的吉凶变化由人事宫位的位移带出；地支宫位不动，所以地支宫位提供的是终生不变的底层条件。
- 宫位不依托星曜而存在，是星曜依托宫位而存在，星曜坐入宫位后才产生影响力。空宫仍然成立，不可因某宫无星而否定该宫所主之人事。
- 每个宫位有宫干，宫干代表该宫的"想法"，可飞出四化以观察该宫意图。但有想法不等于有行动，有行动不等于有结果；结果由双方力量对比决定。

## 二、十二人事宫位主管范围

| 宫位 | 主管 | 必须合参 |
|---|---|---|
| 命宫 | 长相、性情、本质、人品、才能、事业、人生定位与层次 | 断疾厄、断事业时以命宫为准绳 |
| 兄弟宫 | 兄弟姊妹、知己、情感与钱财状况 | 可侧面观察母亲，但兄弟宫非母亲本宫，属借看，不可说直接代表母亲；合作事项须并看 |
| 夫妻宫 | 配偶相貌、性情、事业，婚姻是否美满 | 离异之因常不在夫妻宫本身，须并看命宫、身宫、福德宫、田宅宫 |
| 子女宫 | 子女好坏、性能力（女命改看田宅宫）、合伙生意、本人才华 | 合伙仍须看兄弟宫 |
| 财帛宫 | 财运好坏、衣着打扮 | 判断是否富有须同看田宅宫与福德宫 |
| 疾厄宫 | 身上最弱的器官、是否有意外、书房与办公室情况 | 论疾病须命宫、身宫、疾厄宫三宫合参 |
| 迁移宫 | 外出情况、在外关系、机遇 | — |
| 奴仆宫 | 属下是否得力、朋友相处与帮助力 | — |
| 事业宫 | 学业、地位、所从事行业、创业能力 | 以命宫为准绳 |
| 田宅宫 | 家庭出身、家宅是否安宁、房屋状况 | — |
| 福德宫 | 一生享受、是否幸福、寿元长短 | — |
| 父母宫 | 父母、社会背景、上司老板、文书类事 | — |
| 身宫 | 后天命运，配合命宫看形体、外在表现与一生发展方向 | 身宫落入哪一宫即表现该宫性质：落夫妻宫则对感情感受特别深刻，落迁移宫则一生动荡不宁喜出外，落福德宫则重享受、满足于娱乐。此条口径为暂定，判断时不宜单独据此定论 |

六组对宫线，用于成对取象：命宫—迁移宫为活动线；兄弟宫—奴仆宫为感情线（亦称成就线、财经线）；夫妻宫—事业宫为婚姻线；子女宫—田宅宫为桃花线；财帛宫—福德宫为财福线；父母宫—疾厄宫为文书线。

本宫转换法：本宫即主事之宫。问夫妻，以夫妻宫为本宫；问配偶的事业，则以夫妻宫的事业宫（即福德宫）为本宫。任一宫的迁移宫表示该宫"外面、对面"的事：子女宫为田宅宫的迁移，可看住宅对面的情况；事业宫为夫妻宫的迁移，可看配偶之外的感情对象。

## 四、宫位与宫位的关系

三方四正取法：以本宫为准，取本宫的三合方，再加对宫为四正。三合组为寅午戌、亥卯未、申子辰、巳酉丑。

| 关系 | 取法 | 作用与判定 |
|---|---|---|
| 三合宫 | 每隔三宫，同属一组地支三合 | 影响力最大的一类。命宫、财帛宫、事业宫是最常用的三合宫；三合中任一宫为强宫即带动本宫变好，任一宫为弱宫即带动本宫变差。会照吉星吉化多主吉，会照煞星化忌多主不顺；例外为某些正曜坐命较不畏煞忌 |
| 对宫 | 本宫对面，即地支六冲之宫 | 凶星在对宫为冲，吉星在对宫为照，实务中可统称冲照。与吉星吉化相冲一般主吉，性质是从对面得到好处；与煞星化忌相冲一般主不吉。例外：各宫强弱与内在特性不同，有的宫不畏煞星冲，有的极畏冲；有的被冲动主吉，有的被冲动主凶，须结合具体宫位与正曜判断，不可一律断凶 |
| 夹宫 | 本宫的两个邻宫 | 判断两夹有无煞星化忌或吉星吉化，据此定出对本宫的作用力。多数正曜以三方四正为重，天相例外：天相所在之宫以两夹宫位的好坏为最重 |
| 暗合宫（六合宫） | 命盘中间画竖线，左右对称的两宫：子丑、寅亥、卯戌、辰酉、巳申、午未 | 力量小于三合。吉星吉化多则锦上添花，至少使过程顺利；煞星化忌多则造成妨碍，至少使过程不顺。古法称暗拱：本宫有禄存或化禄而六合宫另有化禄或禄存，为明禄暗禄，彼此加强；本宫有化科而六合宫有化禄或禄存，为科明禄暗，增大化科之力；六合宫见文昌、文曲为文星暗拱，影响考试运但弱于在三方四正 |
| 六害宫 | 命盘中间画横线，上下对称的两宫：子未、丑午、寅巳、卯辰、申亥、酉戌 | 有相害、造成损害之义，影响力小，与三刑、自刑同属可从略之项 |
| 太岁宫 | 本人生肖地支所在之宫 | 生肖与命宫地支重合，称太岁当头坐；此时命宫又有天魁或天钺，吉利性质明显增加。生辰不确切时，另有借命盘上生肖之宫为命宫来推断的做法。此项规则有限，不宜扩充 |
| 身宫 | 见第二节 | 用于加强命局优势或补足命盘缺点，据此判断格局层次：身宫位置好，可自行创业、名利双收；身宫位置不佳，则同格局仍以普通论，仅主福气重而缺上进心 |

不可误用的一条：本宫三合中的两个辅宫彼此之间并不构成三方四正。以命宫为本宫时，财帛宫与迁移宫之间、迁移宫与事业宫之间互相影响力很弱，只有财帛宫与事业宫同属命宫三合面，不可按三方四正处理。

## 五、地支宫位五行与星曜五行的生克

| 地支宫位 | 五行 |
|---|---|
| 辰、戌、丑、未 | 土 |
| 寅、卯 | 木 |
| 巳、午 | 火 |
| 申、酉 | 金 |
| 亥、子 | 水 |

判定步骤：先定宫位五行，再定宫内星曜五行（含阴阳属性），再判生克。

| 生克关系 | 象义变化 | 例 |
|---|---|---|
| 宫生星 | 星曜性质得到支持并加强，包括凶性也被支持 | 廉贞、铃星同属阴火，落寅宫（阳木）则木生火，煞气得到支持，主居处及周围人带煞气；同组合落申宫（金）则无煞气得支持之义 |
| 星宫同类 | 星曜更自由、力量更强；若星克宫，则宫位受损减轻 | 廉贞贪狼在亥宫，贪狼本体属水与亥同类，贪狼更自由、力量更强；廉贞贪狼在巳宫，廉贞本体属火与巳同类，则廉贞力量更强 |
| 宫克星 | 星曜性质受损、象义打折、规模缩小 | 天机属木，天机巨门在木宫，住处附近植物多且越长越高、缺乏修剪；同组合在酉宫，酉金克木，植物有但长不大、长不多，多为有人修剪之境 |
| 星克宫 | 宫位不能为星曜提供支持，反被星曜之力伤害，主灾 | 武曲七杀属金，坐命卯宫（木），卯宫被金伤，命中易有灾难；同组合在酉宫（金）为同类，虽亦有灾，但伤害小得多 |

具体化取象须叠加地支的物象。田宅宫在巳宫见武曲、破军时，巳为阴火，可取地壳之下暗火之象，武曲取金属矿藏，破军取破坏、开拓，合为拥有矿产资源、依靠采矿致富；同一人事宫位改配亥宫，则金属矿藏之义不成立，转为常居外地、住处周围有水域环绕。

基础层推理可用但作用有限：命宫落亥宫、子宫属水，水性流动，较一般人更易去外地乃至漂洋过海；命宫落申宫、酉宫属金，金有自然光泽，故特点较明显、易给人留下印象。

口径限制：地支宫位可判定的规则数量有限，集中在"五行生克改变象义"与"地支物象具体化"两项，未形成完整体系。断盘顺序应先完成人事宫位的论断，再叠加地支宫位的修正，不可用地支宫位覆盖人事宫位的结论。

## 六、辰宫戌宫的限制作用（天罗地网）

辰宫为天罗，戌宫为地网。二宫有"网"的特点，会网住落入其中的全部星曜。

基本效果：星曜变得迟滞，活跃度大大降低，吉性与凶性同时减轻。
- 廉贞化禄坐命而命宫在辰宫或戌宫，吉利性质被限制，不主早年发大财，往往三十多岁以后才逐渐发家致富。
- 擎羊坐命于辰宫、戌宫（擎羊在辰、戌均入庙），本主粗暴凶恶戾气重，受限制后煞气降低，若再见其余吉星吉化，反主大吉。

能否挣脱，取决于星曜力量强弱：力量强则可挣脱，力量不强则不能挣脱。煞星有激发之力，三方四正见煞星会提高挣脱的可能性。

挣脱是否有利，须分组合判定：

| 本宫组合 | 是否宜挣脱 | 处理 |
|---|---|---|
| 吉利组合且能挣脱 | 宜 | 一般为非常好的事 |
| 不吉利、危险的组合而挣脱 | 不宜 | 反主凶，宁可让其被限制在内，不要放出来 |
| 温和星曜坐辰戌又见吉星吉化（如天同） | 宜，但难 | 享受增加而更难挣脱，此时宁在三方四正见若干煞星、化忌以取激发之力，效果更好 |
| 安稳星曜得众多吉星吉化（如廉贞天府，三方四正见左辅、右弼、禄存、化禄） | 不需要 | 可坐享富贵、逐渐进步，靠自身力量积累亦能挣脱束缚，不必借煞星之力强冲 |

判定要点：不可把"能挣脱"一律判为吉、"挣不脱"一律判为凶；先判组合吉凶，再判是否需要挣脱，最后判能否挣脱。此部分只有以上有限规则，未展开为完整体系。

## 七、空宫与借星安宫

空宫指宫内无十四正曜（长生十二神、将前十二神不计入）。

借星安宫的做法：遇空宫，可将对宫星曜全部借入，借来的星曜仍以其本来所在宫位的庙旺利陷为准。

不可"遇空宫即借星"，须按顺序推进：
1. 先观察空宫内部的副曜、杂曜、四化，得初步结论。
2. 再看空宫的对宫与三合宫，合空宫本身情况，得进一步结论。空宫内见禄存、左辅等吉曜而对宫或三合宫又见化禄及吉曜，为吉上加吉；空宫内见擎羊、地劫而对宫或三合宫又见化忌、火星、铃星、地空、破军、七杀、巨门，为凶上加凶。
3. 再看空宫的两夹宫位有无煞星化忌或吉星吉化，判定对空宫的作用力。巳、亥两宫为空宫而被地劫、地空所夹，有损失、孤独、空虚之义；巳宫为空宫且为子女宫，又被地空、地劫所夹，主子女方面有损失。
4. 再看对宫的三合宫，影响力通常较小。

出现"吉上加凶""凶上加吉"时无固定公式，回到星曜、宫位、四化的具体搭配判断。

空宫的特殊结构：空宫无正曜干扰而有火星、地空坐守，三方又有吉星吉化拱凑，可作火空则发论，多主聪明有才、富裕发达；命宫为空宫而有擎羊、地空坐守，无正曜干扰且三方有吉星吉化拱凑，可作金空则鸣论，多主聪明有才、富裕扬名。火星地空、擎羊地空、火星擎羊、铃星陀罗属煞星互制的结构，有爆发力，但爆发之前先吃苦头。成立条件是宫内无正曜；若同宫有正曜（如天府擎羊地空、紫微火星地空同宫坐命），不作此论。

主次原则：一宫之中正曜影响力最大，脱离正曜单论副曜组合易得错误结论。

## 八、大限流年宫位与原局宫位的重叠

移动方式：人事宫位整盘在十二地支上移动，命宫移到下一宫，其余各宫依序跟移；顺行或逆行因盘而异。大限十年一移，流年一年一移。

解释方向（硬性）：宫位移动与星曜互涉，一律解释为"外界来影响本人"，不解释为"本人去影响外界"。大限、流年的命宫走到某宫，即本人处于该宫星曜所构成的环境之中，并被该环境影响。

重叠加强：流年或大限的某宫与原局同名宫重叠时，该宫影响力增大，该宫所主之事在当期显题。若重叠之处又有四化叠加（如叠权、叠忌），影响力进一步放大，判断时以该宫所主之事为当期主线。

星曜互涉的示例规则（均为有条件成立）：
- 巨门坐命者行至贪狼所在之宫（多在第二或第六大限），意志力更薄弱，轻则染酒色烟赌等嗜好，重则触犯官司刑法。
- 天梁坐命者行至贪狼所在之流年，因本性随便、自制力有限，易有私生活问题。
- 破军坐命者行至太阴、天府所在的大限流年，消耗大与命运波折的缺点得到缓解，命运可以好转。
- 天机坐命者行至太阳所在之宫，多可得较大发展；成立机理是天机代表谋臣、本身缺贵气且需人赏识，太阳为贵星能补其贵气并提供贵人运。

上述规则的限制条件：同一正曜因所落宫位、四化与同宫星曜不同而分多种类型。行至受制、自律型的贪狼时，前两条不发生。判定前必须先确定该正曜的具体类型，不可仅凭正曜名套用。

起限口径的差异条件：另有以父母宫、兄弟宫起第一大限的做法，其成立条件是家庭对个人有强压制——此时即便命宫具备天赋，也须按家庭要求发展，若父母宫、兄弟宫恶劣则本人才华被埋没、特长无法培养。个人发展条件充分、家庭压制减弱时，命宫的天赋更易发挥，此起限口径的适用性下降。第二大限行至父母宫或兄弟宫时，师长、同侪与家庭是否和谐为该期主要变量。
