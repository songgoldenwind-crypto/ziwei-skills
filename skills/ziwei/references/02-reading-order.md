# 断盘顺序

## 是否起断

- 须先有所问。所问来自思想或行动上的“动”：已有想法、计划、疑虑或正在推进之事。
- 对方生活安定、没有疑问、也未要求看盘时，不起断。
- 局部规则比较、星曜定义或用户已给出完整命盘要求解释时，不另索所问以外的材料。

## 固定顺序

不得跳步。问原局性格或格局时，做到第 5 步即可，输出仍须带盘头（含四柱），过程段只附当前大限与下一限作为「下一阶段」，不展开流年；问流年、应期或“这几年怎样”时，必须做到第 7 步。

1. **核盘。** 十二人事宫与地支宫对应、宫干宫支、正曜或命无正曜、庙旺利陷、生年四化齐备后才续断。时辰交界不能唯一确定则并列两盘。
2. **定所问与主宫。** 按人事宫定性、按地支宫定形。主看宫与参看宫见 [03-palaces.md](03-palaces.md)。未说明子目标的宽题，只判断当前层次、下一阶段和一个决定条件。
3. **先明格局。** 命宫三方四正是否成格、是否破格。成格条件见 [07-combinations.md](07-combinations.md)。成格且财帛、事业、田宅组合俱佳，层次最高。
4. **次看众星。** 本宫正曜 → 同宫合成性质 → 三方四正会照 → 夹宫。天相以两夹为最重。正曜影响力大于辅曜；脱离正曜单论辅曜、煞曜或四化，判定不完整。
5. **叠四化。** 先生年四化，再大限四化，再流年四化。读作“正在向禄／权／科／忌的方向改变”。三吉化须核落星、落宫、庙旺、三方与该限是否合适。
6. **分男女命、合处境。** 同一结构对男命与女命权重不同，不得统一处理。再结合当事人已说明的现实处境修正层次，不因个人好恶改判。
7. **原局重点 → 大限 → 流年。** 先找出原局已成的格局或凶构、吉煞集中处、生年四化冲起的宫位，再看大限宫位与大限四化，最后看流年。禁止不看原局直接断流年。

## 三层组合必须同时成立

| 层 | 问的是 | 禁止 |
|---|---|---|
| 星曜 + 星曜 | 同宫合成后的性质 | 分别罗列各星原义当作结论 |
| 星曜 + 宫位 | 该人事宫与该地支宫如何改写星性 | 只用“某星入某宫”定案 |
| 宫位 + 宫位 | 三合、对宫、夹宫、暗合、身宫、限运重叠 | 忽略会照与夹宫 |

凡结论只来自单一维度，须回到三层复核后再输出。

## 限运解释方向

- 人事宫位可移动，地支宫位不动。运限吉凶由人事宫位移带出；地支提供终生底层条件。
- 大限、流年命宫走到某宫，解释为该宫星曜环境来影响本人，不解释为本人去影响外界。
- 流年或大限某宫与原局同名宫重叠，该宫所主之事在当期显题；再叠四化则进一步放大。
- 当代起限以命宫为第一大限。仅当家庭压制强、父母宫或兄弟宫很差、才华被埋没时，才改用父母宫或兄弟宫起第一大限。选定后全盘一致。

## 辅佐规则的位置

- 辅弼、昌曲、魁钺增强或修饰正曜，不能代替格局。
- 羊陀火铃空劫改变正曜的稳定性与爆发力，须附着在正曜与宫位上判断。
- 宫干飞化只说明该宫“想做什么”；有意向不等于有结果。双方力量悬殊时，弱势一方的飞化不产生其预期结果。

## 本宫转换

问某宫所主之人的事，以该宫为本宫再取其对应宫。例如问配偶事业，取夫妻宫的事业宫（福德宫）。任一宫的迁移宫表示该宫“外面、对面”的事，不能直接改写成本人的迁移。
