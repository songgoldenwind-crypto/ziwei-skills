# 断盘流程与证据链

流程用于防止漏看关键条件，不要求把每一步写给用户。

## 一、确定任务与范围

- 只排盘：停在盘面核对。
- “算一下／看看这个”：默认原局概览，覆盖命格骨架、做事方式、事业财帛、关系与福德；不自动分析当年。
- 专题：只定一个主宫，并选一至三个确有必要的参看宫。
- 限运：先完成与所问有关的原局主链，再叠大限、流年；用户未问月份或日期时不下钻。
- 规则查询：直接比较成立条件、例外和误判，不索取出生资料。

## 二、建立原局骨架

1. **命身定位。** 命宫给先天表达，身宫看后天用力处；不以命主、身主名称替代命身两宫。
2. **命财官迁。** 核命宫三方四正的主星、庙旺、空宫、吉煞和四化，先看整体支撑，再看单宫。
3. **主星组合。** 本宫正曜先合成，再看三方、对宫、夹宫。天相优先看两夹；空宫按规则借对宫。
4. **格局。** 逐条核成立条件与破格条件。只满足相似外形时称“有某格倾向”，不能直接冠格。
5. **辅煞。** 辅曜提供助力方式，煞曜改变稳定性与代价；二者不能越过正曜独立决定层次。
6. **生年四化。** 写清哪颗星向禄、权、科、忌变化，落在哪一宫，如何改变已建立的主星组合。

## 三、围绕问题取宫

| 问题 | 主宫 | 常用参看 |
|---|---|---|
| 性格、人生主轴 | 命宫 | 身宫、福德、命财官迁 |
| 事业 | 官禄 | 命宫、财帛、迁移、身宫 |
| 财运 | 财帛 | 官禄、田宅、福德、迁移 |
| 婚恋 | 夫妻 | 命宫、福德、相关大限流年 |
| 学业考试 | 命宫或官禄，依问题定 | 父母、福德、昌曲魁钺及四化 |
| 子女 | 子女 | 命宫、夫妻、田宅；只作传统倾向 |
| 健康取象 | 疾厄 | 命宫、身宫、福德；不得作医学诊断 |

问“配偶的事业”等他人事项时，以夫妻宫为本宫重新取其官禄宫，并明确这是宫位转换后的术数推断，不当作对方隐私事实。

## 四、加入时间层

只有问题带时间维度时执行：

1. 原局先确定哪类机会与风险本来存在。
2. 大限看十年环境是否补强、削弱或改写原局主链。
3. 流年看该年是否把同一主题推到台前。
4. 流月、流日只用于缩小已成立事件的窗口，不能凭低层流曜制造原局没有的事件。

每一层都写清“本层命宫叠原局何宫、本层四化落到原局何处”。人事宫移动表示相应环境作用于本人，不解释为本人必然改变外界。

## 五、形成最短证据链

一个重要结论通常需要：

`主宫正曜与庙旺 → 同宫／三方／夹宫修正 → 四化或限运触发 → 现实表现`

至少跨两个层面才可输出。若主链与反证力量接近，给出分叉条件，例如“在稳定组织中表现为 A；若频繁独立冒险，则更易表现为 B”，不要硬压成单一吉凶。

## 六、落笔前复核

- 结论是否回答了用户的问题，而不是只报格局名？
- 是否把盘面事实、传统规则和结合语境的推断混成了一句话？
- 是否有单星定案、空宫断无、三吉化必吉或化忌必凶？
- 是否把古代性别角色、职业标签或婚姻价值判断照搬成现代事实？
- 若问时间，原局、大限、流年是否确实指向同一主题？
- 删除星曜名后若仍可套用多数命盘，是否已改成可核验的具体表达？
