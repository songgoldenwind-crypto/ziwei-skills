# 紫微斗数分层断盘

先核盘，再按格局、组合、四化与限运推断。保留具体条件，不把口诀中的吉凶写成已经证实的现实事实。一个问题先完成一条主判断链，再按需补细节。

## 输入

利用已有的所问、求测人、性别、出生年月日时、出生地、已有命盘或运限日期。只有影响当前判断的信息缺失时才追问；局部规则比较无需强求全盘。无明确所问、也无思想或行动上的“动”时，不主动起断。

命盘核对：出生四柱、十二人事宫与地支宫对应、各宫宫干宫支、正曜（含命无正曜）、庙旺利陷、生年四化、命宫三方四正（命财官迁）。缺任一项即停止断盘。身宫、辅佐杂曜、大限起讫、流曜缺失时，只封锁对应判断范围。时辰落在两时交界而不能唯一确定时，并列两盘，以已发生事实反验，不得任选其一续断。给用户的断语必须先出盘头，把四柱写进去。

排盘读 [01-chart-verification.md](references/01-chart-verification.md)。优先调用 `ziwei-paipan-code` 生成本命盘或运限盘：出生四柱、十二宫、正曜辅曜、庙旺、生年四化、身宫、五行局、大限起讫；运限模式再给大限、流年、流月、流日、流时及各层四化。四柱在输出顶层 `四柱` 与 `ai_context.basic_info.四柱`，年柱用于生年四化核对。调用前先确认 `ziwei_paipan` 命令或源码入口可用；若当前 Agent 未安装排盘模块，则使用用户给出的完整命盘，只追问影响判断的缺失项，不臆造星曜、四化、庙旺或宫位。排盘输出只提供结构，断盘仍执行本技能的规则。出生地只用于校正时辰，不进入后续取象。

```bash
python -m ziwei_paipan --date 1990-05-20 --time 12:30 --gender 男 --location 上海
python -m ziwei_paipan --date 1990-05-20 --time 12:30 --gender 男 --location 上海 --horoscope-date 2026-09-14
```

## 固定执行顺序

1. **定所问与主宫。** 读 [02-reading-order.md](references/02-reading-order.md) 与 [03-palaces.md](references/03-palaces.md)。先确认有所问；再定主看宫与参看宫。问事业不单看官禄，须以命宫为准绳；问财运须合看财帛、田宅、福德。
2. **先明格局。** 读 [07-combinations.md](references/07-combinations.md)。成格与否只是第一层；成格且财帛、事业、田宅组合俱佳者层次最高。未列入的格局不得补入。男命与女命同盘不同断。
3. **次看众星。** 读 [04-main-stars.md](references/04-main-stars.md)。本宫正曜 → 同宫合成 → 三方四正会照 → 夹宫。天相以两夹为重。脱离正曜单论辅曜易错。
4. **标四化。** 读 [06-sihua.md](references/06-sihua.md)。先断生年四化，再叠大限四化，最后叠流年四化。按“某星正在向禄权科忌的方向改变”理解，不可读成已经变成禄星或忌星。三吉化不必主吉，化忌不必主凶。
5. **合参限运。** 问大限、流年或应期时读 [09-luck-cycles.md](references/09-luck-cycles.md)。先定原局重点，再看大限，最后看流年。限运宫位移动一律解释为外界环境影响本人，不解释为本人去影响外界。不得跳过原局直接看流年。
6. **取象与收束。** 先定此问题的趋势，再按需取象。输出纪律见 [11-output-discipline.md](references/11-output-discipline.md)。

## 体系边界

- 以象义与组合为主。禁止拿到命盘先看星曜阴阳五行生克；太阳与文昌一般主吉，不得按火克金改判。
- 宫干飞化只表示该宫意向，不得脱离星曜与宫位强弱单独使用，更不得把飞化夸大成唯一断法。
- 辅星力量不如十四正曜。空宫仍然成立，禁止由空宫推出“该六亲不存在”或“该类事不会发生”。
- 禄、权、科不是必吉，化忌不是必凶。贪狼化忌不忌、太阴亥宫化忌不忌、四墓宫化忌不忌，均有条件，不可作无条件通则。
- 起大限口径：当代以命宫起第一大限；家庭压制强时才改用父母宫或兄弟宫起限。两种口径不得混用于同一盘。
- 流月四化随节气改月干，流月宫位仍按农历月走，两者分开，不得同步调整。
- 不引入另一套“只看飞星、只看五行、只看杂曜”的规则覆盖本法。用户要求比较时，分开呈现。

## 输出

给用户的正文默认五段。只解释决定结论的节点。仅问规则或局部条件比较时，可省盘头与应期，其余断盘不得省略盘头。

1. **盘头。** 性别、公历、真太阳时与时辰（单盘或并盘）、四柱（年 月 日 时）、命宫（地支 + 正曜 + 庙旺 + 本宫四化）、身宫落在哪一人事宫、五行局、命主身主、生年四化落星。四柱取排盘顶层 `四柱`，时柱必须与排盘时辰一致；有四柱却不写进盘头，视为核盘未完成。四柱只核年干与时辰，禁止另起八字断法。
2. **判断。** 一至三句给出一个主判断：层次、能走到哪一步。不要先贴十二宫。
3. **主因。** 二至四个节点：主宫正曜、同宫或三方关键星、四化、限运冲起。命宫三方四正只取命、财帛、官禄、迁移（三合加对宫），不得把四墓宫当成三方。
4. **过程 / 应期。** 问原局性格或格局时，写当前大限与下一限即可；问流年或应期才落到流年。没有三层四化与宫位重叠，不落到具体日。
5. **限制。** 只留一个最关键的未决条件或反证。用户问建议，或病点对应本人能做的动作时，再给「可做之事」。

模板、反例与边界见 [11-output-discipline.md](references/11-output-discipline.md)。星曜、神煞和身体物类属于象义，不能据此确认真实人的疾病、死亡、犯罪、性关系或胎儿性别等事实；灾害象不作真实灾害预报，财象不作交易保证。不输出没有规则支持的金额、概率、寿数、涨幅或精确时点。命盘只提供信息，不越权替当事人做人生决定。
