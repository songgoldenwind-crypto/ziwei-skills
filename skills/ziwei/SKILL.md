# 紫微斗数排盘与解读

先把可计算的盘面事实与术数解释分开，再围绕用户真正问的事组织答案。不要把参考资料逐条复述成断语，也不要用“中层、不错、有波折”这类空泛等级替代具体判断。

## 先识别任务

| 用户意图 | 默认处理 |
|---|---|
| “排个盘”“核对这个盘” | 只给排盘结果、时间校正和关键字段；不主动扩写吉凶 |
| 给出生资料并说“算一下／看看这个” | 做原局概览；不再追问想看哪个专题 |
| 问事业、财运、婚恋、学业、子女等 | 只展开该专题及必要参看宫 |
| 问今年、某年、这几年、何时 | 原局为底，叠大限与目标流年；仅在用户需要时下钻流月、流日 |
| 问星曜、格局、四化规则 | 直接作规则解释或条件比较，无需个人出生资料 |

若用户明确要全盘、逐宫或教学式分析，再扩大篇幅。不要把一次宽泛请求擅自改造成单一的财富或身份等级评判。

## 输入与排盘

自行起盘需要公历出生日期、当地钟表时间、性别和出生城市。只缺一项时只问这一项；用户已给完整命盘时，不重复索取出生资料。用户给的是农历日期时，必须明确阴历、是否闰月，并使用可靠换算或宿主排盘能力，不能把农历数字直接当公历。

排盘与字段门槛读 [01-chart-verification.md](references/01-chart-verification.md)。本技能分发包自带排盘入口；在技能目录运行：

```bash
python scripts/run_paipan.py --date 1990-05-20 --time 12:30 --gender 男 --location 上海
python scripts/run_paipan.py --date 1990-05-20 --time 12:30 --gender 男 --location 上海 --horoscope-date 2026-09-14
```

若宿主已有可信排盘工具，可直接使用。若本地依赖不可用且当前环境不允许安装，说明缺少什么，并请用户提供完整盘面；不得凭记忆补星曜、宫位、庙旺或四化。

核对时至少确认：输入钟表时间、解析到的地点、真太阳时、是否跨时辰、出生四柱、十二宫、正曜庙旺、生年四化、身宫、命宫三方四正。时间靠近时辰边界或用户说明时间只是约数时，按 [01-chart-verification.md](references/01-chart-verification.md) 的双盘规则处理。

## 分析流程

具体次序读 [02-reading-order.md](references/02-reading-order.md)。内部按以下链路完成，输出不必逐项展示：

1. 先锁定任务模式、主宫和参看宫；宫位映射见 [03-palaces.md](references/03-palaces.md)。
2. 从原局找骨架：命宫与身宫、命财官迁、主星组合、成格与破格。格局条件见 [07-combinations.md](references/07-combinations.md)。
3. 只读取主链涉及的正曜段落；正曜规则见 [04-main-stars.md](references/04-main-stars.md)，对应星系与空宫借星见 [08-star-systems.md](references/08-star-systems.md)。
4. 用辅煞修正强弱，不让小星越级取代正曜；需要时读 [05-auxiliary-stars.md](references/05-auxiliary-stars.md)。
5. 先看生年四化如何改变原局，再按问题叠大限、流年四化；读 [06-sihua.md](references/06-sihua.md)。
6. 只有用户问运势或时间时才读 [09-luck-cycles.md](references/09-luck-cycles.md)，不得跳过原局直接用流年星曜定吉凶。
7. 财运、学历、子女等专门规则按需读 [10-topic-reading.md](references/10-topic-reading.md)。
8. 找出支持主判断的最短证据链，以及真正能改变结论的反证或现实条件。

## 判断原则

- 同一结论至少落在“星曜组合 + 所在宫位 + 会照／四化／限运”中的两个层面；单星只能作候选象，不能定案。
- 先说结构更支持什么、代价在哪里、什么条件下会转好或转差，再谈传统格局名。格局名不是结论本身。
- 生年四化描述原局倾向；大限、流年四化只在其时间层生效。禄权科不自动等于吉，化忌也不自动等于凶。
- 空宫是没有十四正曜，不是“没有婚姻、没有事业、没有子女”；按规则借对宫并合看三方。
- 宫干飞化可作补充意向，不得覆盖正曜、庙旺、三方和生年四化的主链。
- 男女差异只在参考规则明确给出且确实影响当前问题时使用；不要把古代性别角色、职业或婚姻观直接当作现代事实。
- 盘面信息不足时缩小结论范围，不要因为缺一个非关键杂曜就废弃整张盘。

## 输出

按任务选择格式，不强迫所有回答套同一个五段模板。详细规范与示例见 [11-output-discipline.md](references/11-output-discipline.md)。

- **排盘／核盘：** 时间校正与地点 → 四柱与命身 → 生年四化 → 关键核对项 → 边界提示。
- **原局概览：** 盘面摘要 → 总纲 → 做事方式与优势短板 → 事业财帛 → 关系与福德 → 一条关键条件。没有问当下运势时，不强塞当前与下一大限。
- **专题分析：** 结论先行 → 二至四条盘面依据 → 有关的现实表现与条件 → 必要时给可执行建议。
- **限运分析：** 原局底色 → 当前大限 → 目标流年／月份 → 机会与风险窗口 → 可验证信号。时间精度不得超过盘面与输入精度。
- **规则解释：** 条件、作用、例外、常见误判。

盘面摘要只写有助于用户核对的内容，通常三至五行；四柱保留，但不另起八字、十神或日主分析。正文优先使用自然语言，术语首次出现时顺手解释。每个重要判断紧跟盘面依据，不把依据集中堆到末尾。

星曜和神煞只作传统术数象义，不作为疾病、死亡、犯罪、出轨、胎儿性别或投资结果的事实证明。医疗、法律和财务问题只能给现实世界的核验与专业求助建议，不给确定性保证。
