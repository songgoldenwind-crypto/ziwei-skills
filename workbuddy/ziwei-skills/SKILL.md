# 紫微斗数全平台套装

这是 WorkBuddy SkillsHub 的单入口完整包。完整遵守核盘、取宫、格局、四化、限运和输出边界。排盘只生成结构，断盘仍执行方法文件中的规则。

## 方法路由

- 排盘、核盘、原局或大限流年分析，以及事业、财运、婚姻、学业等具体事项，读取并完整遵守 [紫微斗数](references/ziwei/method.md)。
- 用户要求与另一套飞星或五行生克方法比较时，分别完成两栏判断并说明各自依据，不合成一套新规则。

读取方法文件后，只按当前问题需要继续读取它列出的 `@references/...`。不要默认把全部参考资料装入上下文。

## 排盘

用户给出出生年月日时、性别、出生地或要求核盘时，优先使用宿主已有排盘能力。需要本地确定性排盘时，使用 `scripts/ziwei-paipan/`：

```bash
python -m ziwei_paipan --date 1990-05-20 --time 12:30 --gender 男 --location 上海
```

在 `scripts/ziwei-paipan/` 目录下运行，或先把该目录加入 `PYTHONPATH`。按当地民用时间自动校正真太阳时；先阅读 `scripts/ziwei-paipan/README.md` 并安装其中固定的 Python 依赖。只给出生日期也能生成基础盘，但缺时辰时不得续断。

运限盘加 `--horoscope-date`。排盘只生成结构，断盘仍执行选定方法的规则。

## 输出边界

先给盘头：性别、真太阳时与时辰、四柱、命身、五行局、生年四化。再直接回答所问：判断、组合链、过程或应期、一个限制。有四柱必须写入盘头；四柱只核年干与时辰，不另起八字断。命盘不作为医疗诊断、死亡断言、犯罪指认、他人隐私事实、胎儿性别确认或证券交易保证的依据。
