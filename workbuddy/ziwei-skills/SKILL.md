# 紫微斗数全平台套装

这是 WorkBuddy SkillsHub 的单入口完整包，包含断盘方法、参考规则与本地排盘模块。

## 使用方法

- 排盘、核盘、原局概览、事业财运婚恋专题或大限流年分析，先完整读取 [紫微斗数方法](references/ziwei/method.md)，再只加载当前主链需要的参考文件。
- “排个盘”只返回盘面；给出生资料说“算一下”默认做原局概览；问具体事项只展开该专题；带年份或“现在”才加入限运。
- 用户要求比较其他飞星或五行体系时，分开列出各自口径，不拼成一套新规则。

## 排盘

出生资料须有公历年月日、当地钟表时间、性别和出生城市。在本套装目录运行：

```bash
python scripts/ziwei-paipan/run.py --date 1990-05-20 --time 12:30 --gender 男 --location 上海
```

运限盘加 `--horoscope-date YYYY-MM-DD`。首次使用若缺 Python 依赖，按 `scripts/ziwei-paipan/README.md` 安装。排盘结果须核对地点解析、真太阳时、是否跨时辰、四柱、命身、生年四化及命财官迁；排盘事实与术数解释分开。

## 输出边界

答案围绕用户所问，重要判断紧跟盘面依据。原局概览不强制塞入当前大限，专题不罗列无关十二宫，限运不跳过原局。四柱只用于核年干与时辰，不另起八字断法。命盘不能用来确认疾病、死亡、犯罪、出轨、胎儿性别或投资结果。
